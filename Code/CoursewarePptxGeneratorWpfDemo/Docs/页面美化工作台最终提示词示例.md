## 二、运行时差异说明

实际输出时，程序会根据当前页面和发送快照替换上述占位内容：

- 当前页完整 Markdown 将逐字保留，不进行摘要、截断或 JSON 字符串转义；
- Markdown 外层围栏会根据原文中的最长连续反引号动态生成；
- Theme 2.0 的两份参考 SlideML 将使用完整 XML 原文；
- 没有前页、后页、警告、画布诊断或附件时，对应位置填写“无”，不输出 `null`；
- 当前页没有引用资源时，资源清单填写“无。不得创建任何图片资源 ID。”；
- 截图说明以发送瞬间实际附带的附件快照为准；
- 安全区像素值根据当前页实际渲染画布确定性计算；
- 这份业务提示词外层仍由流式 SlideML System Prompt 提供协议、Schema、合并、检查和工具规则；
- 课件专用流式用户包装不再附加“尽量使用浅色主题”或虚构占位资源等通用建议。
