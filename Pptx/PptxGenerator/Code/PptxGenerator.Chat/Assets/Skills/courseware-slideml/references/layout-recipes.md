## 1 基础栅格

| 项 | 数值 |
| --- | --- |
| 左右边距（图文页） | 120，内容宽 1040，右边界 1200 |
| 左右边距（满版／封面） | 56 |
| 页眉小字 | `Y=34`，12–13px |
| 主标题 | `Y=54`，34px |
| 标题下分隔线 | `Y=108`，高 1 |
| 内容区 | `Y=132` 起，底边 668（可用高 536） |
| 页码／页脚 | `Y=690`，12px |

标题带用同一套：页眉小字在上、主标题在下、一条细线收尾。整册课件每页都保留这条带，翻页时视觉不跳。

**关于文本 `Height`**：上表给的是视觉网格值，不含盒高。单行文本的渲染高度恒为 `1.32 × FontSize + 20`（12px→36，22px→49，34px→66）。两种取舍：

- 想清掉溢出警告 → 按公式给足 `Height`，页面上下元素相应微调。
- 想保持这套紧凑网格 → 不写 `Height`，让引擎自己算；只在必须固定高度时才碰它。

## 2 骨架：封面页

- 左边距 56，标题左对齐，不用居中。
- 层级：科目／章节小字 → 主书名（48–56px，衬线）→ 副标题或课时（18px 灰）→ 底部作者／日期小字。
- 可放一张主题照片在右侧（宽 520–600），`Stretch="UniformToFill"`，不加圆角描边。
- 不要放装饰圆、色块斜切、居中堆叠的三行标题。

## 3 骨架：章节过渡页

- 大号章节号（72–96px，浅灰或强调色，透明度可降到 0.15–0.3）
- 章节名 34–40px
- 一句话导语 18px 灰
- 留白占页面 60% 以上，只放三样东西

## 4 骨架：三行横向对照

适合"多个对象用同一套指标比较"的页面（比较快慢、比较大小、归纳规律）。

- 三行等高：行高 176，行间分隔线 `Height=1`，行距 16；三行占 `Y=124`–668。
- 每行内部固定三栏，列边界全页统一：

| 栏 | X 范围 | 内容 |
| --- | --- | --- |
| 图 | 120–270（宽 150，高 112） | 照片，`UniformToFill` |
| 过程 | 300–560 | 过程轴：一条 `Height=1` 横线 + 两端 1px 刻度；轴上方 15px 说明；两端速度 17px |
| 结论 | 724–1200 | 竖分隔线在 700；上方 15px 灰字写中间量，下方 22px 写结论名 + 26px 加粗强调色写结果 |

关键：三行的速度文字、结论文字必须落在同一批 Y 基准值和同一条右边界上。用同一份坐标复制三份，只改文字。

**右对齐怎么落地**：`TextAlignment="Right"` 生效，但文字末端距右边界约 20px（见 `renderer-behavior.md` 5.4）。所以：

- 三行都用同字号 + `TextAlignment="Right"` + 同一个 `Width` → 彼此严格对齐，可以放心用。
- 要真正贴住 1200 这条边 → 把 `X` 右移约 20，或干脆算好 `X` 不用对齐属性。
- `HorizontalAlignment` 无效，别用。

## 5 骨架：知识点拆解页

适合"一个概念分几个维度讲"（定义／公式／单位／意义）。

- `Y=132` 起，四条内容纵向排布，条目间距 16–20。
- 每条左侧一个 15–18px 编号或短标签（宽度固定 64，右对齐），右侧正文。
- 公式单独一行，字号比正文大 6–10px 并加粗；单位可与公式同行，用稍小的字号。
- 条目之间用 1px 细线分隔或纯留白，不要每条都套一张圆角卡片。
- 页脚可放一句"注意"或推导提示，14px 灰。

## 6 骨架：图文两栏

- 图占 40%（宽 420，高 320 以内），文占其余。
- 图左文右：图 `X=120`，文 `X=580`，宽 620。
- 文左图右：镜像到 `X=120` / `X=740`。
- 一段一个意思，段间距 20；要点用短横线或小圆点，缩进 24。
- 图下可加 12px 图注，颜色比正文浅。

## 7 骨架：过程轴

适合讲运动过程、时间顺序、反应流程。

- 主轴水平线 `Height=1`，长度按内容 300–900，垂直居中于该区块。
- 起止两端各加 1px 竖直短刻度（高 13，即轴线上下各 6）。
- 关键节点用小竖线或 8×8 方块标在轴上，节点标签在轴上方 15px 居中，说明文字在轴下方 14px。
- 箭头不要用 `▶` 之类字符（会让渲染崩溃），用线段 + 短边拼，或两端刻度表达区间。

## 8 骨架：表格页

- 数据行用 `Rect` 画 1px 横线，不用每格描边；表头行加浅底色（如 `#F4F5F3`）。
- 表头浅底色若是直角块，用带子元素的 `Panel` 实现；`Rect` 做出来四角是圆的。
- 列宽取整（如 240／200／300／300），标题行高 44，数据行高 40。
- 数字列右对齐、文字列左对齐；单位写在表头括号里，不逐行重复。
- 数字列的右对齐与前面一样，含约 20px 内缩；同一列统一 `Width` 与 `TextAlignment` 即可整齐。
- 表格总宽与内容区同宽（1040），右边界对齐 1200。

## 9 骨架：小结／习题页

- 小结：3–5 条要点，每条一行，前置标记统一；底部留一条"本课主线"总结句，字号略大。
- 习题：题干 20–22px；选项两列或四列等宽排布，缩进对齐，选项文字左对齐；题干与选项间留 24。
- 答案若要课上揭示，单独放一个浅底块（如 `#F4F5F3`）承载，方便后续遮挡／逐条显示。浅底块要直角就用带子元素的 `Panel`。

## 10 流式布局怎么用

绝对坐标仍是默认，也最好控制。以下情形才改用 `Panel Layout="Horizontal"`（或 `Vertical`）：

- 一排等宽卡片、一排指标条、一组等高选项——数量 ≥ 3 且尺寸一致。
- 间距要反复微调：改 `Gap` 一个数字，全排一起动，比改 N 个 X 快。
- 明细内容仍用绝对坐标：照片、数值、结论分别摆。**排列轴上不要写 `X`／`Y`**，否则该元素脱离流式，位置和顺序都不受 `Gap` 控制。
- 子元素间距 = `max(Gap, 前元素 right Margin + 后元素 left Margin)`，不是两者相加。想严格等距就用 `Gap` 且不给 `Margin`。
- 交叉轴默认 **Top** 对齐，子元素不会垂直居中；要居中就自己写交叉轴坐标。
- 不支持换行（没有 Wrap）。一组超过 4 个就先算总宽：`n × Width + (n-1) × Gap ≤ 内容宽 1040`，超了会被裁剪并给出警告。
- 流式里的 `TextElement` 想自动换行，仍然必须显式写 `Width`；不写就是单行不换行。
- `Panel` 的 `Background` 是直角的，很适合当"一排卡片"的底板；但**必须带子元素**，否则会忽略宽高。

## 11 间距与密度

| 关系 | 间距 |
| --- | --- |
| 组内元素（标题与其说明、数值与其单位） | 6–10 |
| 条目之间 | 16 |
| 区块之间 | 24–32 |
| 标题带与内容区 | 24 |
| 内容区与页脚 | 20 以上 |

- 字号阶梯只用 4–5 级（如 34／22／17／15／13），不要每处都不同。
- 一页的元素数量宁少勿多：去掉纯装饰元素比缩小字号更有效。
- 中文行高按 `1.32 × 字号 + 20` 给 `Height`（22px 正文 → 49，34px 标题 → 66），这是引擎实际使用的值；按 1.6–1.8 倍字号给会偏小并持续报警告。
