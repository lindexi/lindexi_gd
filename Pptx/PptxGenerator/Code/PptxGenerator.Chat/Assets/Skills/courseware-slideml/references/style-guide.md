## 1 先确认风格

1. 用户已说清风格 → 直接照做，不必再问。
2. 用户说"按你的审美" → 自行决定，交付时用一两句说明为什么这么排。
3. 用户没说 → 给两三个候选，每个一句话描述，让对方挑：例如"白底印刷风（像教材排版，最稳重）／清爽卡片风（分块清楚，适合要点多）／深色投影风（对比强，适合大教室）"。
4. 一旦定了，整套课件沿用同一套底色、标题带、字体分工、强调色。单页另行花式会让翻页时明显割裂。

## 2 预设一：白底印刷风

默认推荐。最不像模板，也最耐看。

| 项 | 值 |
| --- | --- |
| 页面底色 | `#FFFFFF` |
| 主文字 | `#1F2328` |
| 次要文字 | `#6B7280` |
| 注释／页眉 | `#9A9A9A` |
| 分隔线 | `#D8D8D4`（主）／`#EDEDEA`（次） |
| 强调色 | `#A34A31`（砖红）或 `#2F5D8A`（靛蓝），全页选一个 |
| 描边 | 1px，暖灰 |
| 字体 | 标题、数值用 `SimSun`；页眉、注释用 `Microsoft YaHei` |

要点：靠细线、留白、字号差建立层级；不铺色块，不用投影。

**直角怎么落地**：`Rect` 恒有圆角（`CornerRadius="0"` 也消不掉，见 `renderer-behavior.md` 5.2）。所以本风格的"细线框／色块"有两种做法：

- 横线、竖线、分隔线 → 用 `Rect`，1px 高度下圆角看不出来，没问题。
- 需要直角矩形底色 → 用 `Panel` 承载背景，**并且给它至少一个子元素**（否则 `Panel` 会忽略宽高）。
- 实在只需要一个小色块，就接受 `Rect` 的圆角，不要试图强行去角。

## 3 预设二：清爽卡片风

要点多、需要分块呈现时用。注意控制装饰数量。

| 项 | 值 |
| --- | --- |
| 页面底色 | `#F6F8FB` |
| 卡片底色 | `#FFFFFF`，描边 `#E3EAF5`，圆角 12，内边距 20 |
| 主文字 | `#232A33` |
| 次要文字 | `#5B6672` |
| 强调色 | `#2F6FED`，只用在一处重点 |
| 字体 | 全页 `Microsoft YaHei`，标题加粗 |

要点：卡片 ≤ 4 张；不要给每张卡加彩色左侧色条；**不要加阴影**（本构建的 `Shadow` 不生效，写了也没用）；不要嵌套第二层卡片。

## 4 预设三：深色投影风

大教室、投影环境亮时用。

| 项 | 值 |
| --- | --- |
| 页面底色 | `#10161F` |
| 卡块 | `#1A222E` |
| 主文字 | `#E8EDF3` |
| 次要文字 | `#92A0B0` |
| 强调色 | `#E0A33E` |
| 字体 | `Microsoft YaHei`，标题加粗 |

要点：深色底下字重偏细会发虚，正文至少 20px；图片注意加浅色描边避免融进背景。渐变在这里比较好用（深底低对比渐变能做出层次），但别做高饱和彩色渐变。

## 5 字号阶梯

1280 × 720 画布，只用这几级，避免一页出现七八种字号。

| 用途 | 字号（px） |
| --- | --- |
| 封面主标题 | 48–56 |
| 页面主标题 | 34–40 |
| 章节号 | 72–96（可降透明度） |
| 重点数值／公式 | 26–30 |
| 正文 | 20–24 |
| 副标题／引导语 | 16–18 |
| 条目说明／轴标签 | 15–17 |
| 注释／图注 | 14 |
| 页眉小字／页码 | 12–13 |

正文不小于 18；低于 14px 的正文在投影环境基本不可读。

**一律写绝对 px。** 官方规范里的 `L1`~`L5` 字号等级在当前构建中不生效——实测 `FontSize="L3"` 会在 `errors` 里报「不是有效的数值」，元素回退到 16px。看到规范里的等级描述时，换算成 px 再写。

两个默认值要记住：省略 `FontSize` 是 `16px`，省略 `FontName` 是 `Microsoft YaHei`（宋体标题必须显式写 `FontName="SimSun"`）。

**行高要按公式给**：单行高度 = `1.32 × FontSize + 20`。34px 标题至少要 65px 高，22px 正文至少要 49px。给不够会报 `ActualLineCount` 溢出警告（画面不裁字，但修改 `Height` 才能清掉警告）。

## 6 字体用法

- `FontName` 写中文名（`微软雅黑`、`宋体`）或族名（`Microsoft YaHei`、`SimSun`），两者实测都生效。
- **字体分工制造对比**：衬线（宋体）承担标题与数值，无衬线（雅黑）承担页眉、注释、轴标签。全页单一字体最容易显得像自动生成。
- 中文里避免给数字配 Times New Roman 斜体——中英混排时斜体数字会显得与周围脱节。
- 数值与单位之间留一个空格：`200 m/s`、`1 m/s²`。符号本身保持原样：`Δv`、`Δt`、`v₀`、`vₜ`。
- 中英文混排不要用 `IsItalic`，斜体中文会被渲染成机械倾斜，且可能触发字体回退警告。
- 需要局部变色／加粗时**不要用 `Span`**（顺序会被反转），拆成多个 `TextElement` 分别定位。

## 7 反模式对照表

用户说"AI 味重"时，基本命中了左列的组合。

| 反模式 | 为什么像自动生成 | 替换做法 |
| --- | --- | --- |
| 每块内容都套大圆角卡片 | 模板默认样式，与内容逻辑无关 | 去掉卡片，改用细线或留白分隔 |
| 彩色左侧色条分色 | 靠颜色而非层级区分，信息冗余 | 全页单一强调色，或直接去掉 |
| 装饰圆、光斑、斜切背景 | 纯装饰，不承载信息 | 删掉，纯色底 |
| 为大面积渐变而用渐变 | 视觉噪音，压缩文字对比 | 纯色底或极浅底色；确有需要时渐变只做极低对比的底 |
| 胶囊标签／徽章（如【讨论与交流】） | 装饰性强，换成小字更稳 | 灰色小字页眉 |
| 超大彩色数字单独炫耀 | 抢走正文注意力 | 与其他数值同列同字号，仅加粗或单色强调 |
| 三到五个彩色圆圈序号 | 图标化过度，弱化文字 | 纯数字或短横线标记 |
| 全页居中、居中、再居中 | 缺少对齐基准 | 左对齐正文 + 统一左边界 |
| 每页七八种字号 | 无层级节制 | 只用 4–5 级阶梯 |
| emoji 当图标 | 风格断裂 | 删掉，或用简单形状 |

能力边界（别把"不生效"当成"不能用"的审美判断）：

- 渐变：**能用**，且 `Rect`／`Panel` 都行。反模式与否取决于对比强度和信息作用，不取决于技术可行性。
- 阴影：当前构建**不生效**。想要"浮起"效果只能靠底色深浅差，不要写 `Shadow` 后以为生效了。
- 圆角：`Rect` 只能圆角，无法置 0；直角请用 `Panel`。

## 8 颜色用量

- 60／30／10：底色 60%，文字与中性灰 30%，强调色 10%。
- 一页强调色最多两处，且必须是"这一页最该被看见的东西"。
- 红色慎用：满屏红字等于没有重点。要突出数值就只染那一个数值。
- 正文颜色不要用纯黑 `#000000`，`#1F2328` 一类的近黑更耐看。
- 深底配浅字时，正文不要低于 20px，否则投影会发虚。

## 9 何时可以偏离

- 用户给了品牌色、学校模板、指定字体 → 优先服从，其余按本文件的比例与网格执行。
- 低年级课件：字号整体上调一级，强调色可增至两个，装饰可比预设多一样，但网格与对齐不变。
- 警示内容（实验安全、易错点）：允许用一次高饱和红，且仅限该处。
- 学科特性：物理／化学的示意图可用彩色标注（不同分量不同色），这属于"承载信息"的用色，不受单色限制。
