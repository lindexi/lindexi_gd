## 二、运行时差异说明

实际输出时，程序会根据当前页面和发送快照替换上述占位内容：

- 主题分析给出的整体视觉风格、字号、背景与视觉效果、版式原则均使用原文，不进行二次结构化、归纳或改写；
- 当前页完整 Markdown 将逐字保留，不进行摘要、截断或 JSON 字符串转义；
- 当前页和相邻页 Markdown 的外层围栏会分别根据原文中的最长连续反引号动态生成；
- 两份参考 SlideML 将使用完整 XML 原文；
- 没有前页或后页时，对应位置填写“无”，不输出 `null`；
- 原始页面截图作为当前消息的视觉附件独立发送，不在提示词中写入附件文件名或路径；
- 安全区像素值根据当前页实际渲染画布确定性计算；
- 这份业务提示词外层仍由流式 SlideML System Prompt 提供协议、Schema、合并、检查和工具规则；
- 课件专用流式用户包装不再附加“尽量使用浅色主题”或虚构占位资源等通用建议。
