# CoursewarePptxGeneratorWpfDemo 课件主题分析重构方案设计

> 文档状态：已落地。
> 当前真实流程以 [`课件打开、主题分析与页面美化完整流程.md`](./课件打开、主题分析与页面美化完整流程.md) 为准。

## 一、目标与边界

主题分析负责从整份课件形成一份轻量、统一且可被页面工作台直接消费的视觉主题，不预先替页面 Agent 分类页面，也不生成与下游无关的中间分析产物。

主题分析不发送截图。课件截图仍用于缩略图和单页美化首轮附件。课件导出格式、相对路径和目录越界校验属于加载阶段，不属于主题 Agent。

## 二、当前数据流

```text
CoursewareFolderLoader
  -> CoursewareStyleUsageSummaryBuilder
  -> CoursewareThemeAnalysisPromptBuilder
  -> CopilotCoursewareThemeAgent
  -> CoursewareThemeSubmissionTool
  -> CoursewareThemeValidator
  -> CoursewareThemeSlideMlValidator
  -> CoursewareThemeAnalysisResult
  -> CoursewareThemeAnalysisSnapshotStore v2
  -> CoursewareSlideWorkspaceViewModel
```

### 2.1 加载

加载器读取 `Courseware.json`、全部页面 Markdown、截图和资源索引，并在加载阶段验证页面顺序、稳定身份、有限正数画布、Markdown 页面信息一致性、资源结构和路径边界。缺失截图或资源实体只产生 Warning。

### 2.2 主题输入

本地只汇总代码块外结构化元数据中的字体、字号和颜色。每类按次数降序、值稳定排序，最多 12 项。

主题 Prompt 先写入固定任务与样式参考，再按页面稳定顺序逐字追加全部 `MarkdownText`。页面之间只使用水平分隔线，不执行摘要、裁剪、转义或内容改写。

### 2.3 Agent 协议

每次分析创建独立主题会话，只暴露 `submit_courseware_theme_analysis`。首轮发送完整输入；校验失败后在同一会话只发送问题列表和重新提交要求。最多三轮，每轮发送前执行上下文预算检查。

## 三、Theme 2.0

`CoursewareThemeAnalysisResult` 只持有一个 `CoursewareTheme`。Theme 2.0 字段为：

- `SchemaVersion`；
- `ColorSuggestions`；
- `Fonts.Chinese` 与 `Fonts.Western`；
- `Style`；
- `SafeArea` 四边比例；
- `SpacingAndVisualEffects`；
- `LayoutPrinciples`；
- `CoverPageSlideMl`；
- `ContentPageSlideMl`。

Theme 不保存分析耗时、页数统计、能力状态、页面分类或兼容主题。

## 四、SlideML 校验

两份参考 SlideML 都是完整 `Page` XML 文档，并共享同一套完整文档 Schema 与 Prompt 规范。校验包括：

1. XML 声明、唯一根元素和根外内容；
2. 标签、属性、父子层级和资源 ID；
3. 禁止流式协议；
4. 文本可见性和固定高度；
5. 课件第一页实际画布上的生产解析、布局和 WPF 渲染；
6. 越界、裁剪和溢出 Warning 作为阻断问题。

后台校验使用独立 STA Dispatcher。渲染位图在跨线程返回前冻结；无应用 UI 线程访问权时使用标准 DPI。

## 五、页面工作台消费

首次创建工作台时，各页面共享同一个 Theme 实例。页面首轮结构化 Prompt 包含当前页完整 Markdown、相邻页摘要、实际资源、截图附件事实和完整 Theme 2.0 原文。

封面页与内容页 SlideML 是参考结构，不是页面分类结论。页面 Agent 可采用、融合或忽略参考结构。已经开始的页面会话和用户编辑过的草稿不会被重新分析结果静默覆盖。

## 六、快照 v2

快照目录包含：

```text
CoursewareThemeAnalysis.json
Courseware.json
Theme/Theme.json
Slides/...
Resources/...
```

清单使用整数版本 `2`，只记录创建时间、课件清单路径和 Theme 文件路径。快照加载重新执行普通导出格式校验、Theme 2.0 字段校验和两份真实 SlideML 校验。v1 与未知版本明确拒绝。

快照不使用内容哈希；快照内 Markdown 修改后，只要仍符合导出格式，就按当前内容恢复。

## 七、状态、取消与并发

- 普通课件只有在 Theme 校验和快照回读成功后才提交结果；
- 失败和取消保留已加载课件与重试入口；
- 同一主题 Agent 的并发分析隔离会话、工具和结果；
- 页面运行时按需创建，不同页面可并发生成；
- 单页取消不影响其他页面；
- 分析页、工作台往返和重新分析保留已建立页面状态。
