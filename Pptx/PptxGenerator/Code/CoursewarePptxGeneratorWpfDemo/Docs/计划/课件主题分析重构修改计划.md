## 执行中修复的真实回归

最终全量测试发现 WPF 真实渲染在 UI 测试顺序下可能访问其他线程拥有的应用窗口或返回未冻结位图。已完成以下根因修复：

- 后台主题校验固定使用独立 STA Dispatcher；
- 应用 Dispatcher 关闭时不再向其投递；
- 渲染输出和加载位图在返回前冻结；
- 后台线程无应用 Dispatcher 访问权时使用标准 DPI；
- 真实渲染错误保留完整技术详情。

该修复不恢复任何旧主题语义。
