# 课件打开、主题分析与页面美化完整流程

> 本文描述 `CoursewarePptxGeneratorWpfDemo` 当前代码已经落地的真实流程。
> 主题分析重构已完成；当前契约是轻量 Theme 2.0，不存在旧主题兼容路径、默认主题回退或旧快照自动迁移。

## 一、流程总览

```text
选择普通课件目录或主题快照 v2
  -> 加载并校验课件导出格式
  -> 普通目录：汇总样式参考并逐字拼接全部页面 Markdown
  -> 独立主题 Agent 最多三轮提交和修复 Theme 2.0
  -> 字段校验 + 完整 SlideML 结构校验 + 真实 WPF 渲染校验
  -> 原子保存并回读主题快照 v2
  -> 创建真实逐页美化工作台
  -> 按需初始化选中页运行时
  -> 当前页 Prompt 携带完整 Theme 2.0、页面 Markdown、相邻页摘要和附件状态
  -> 生成、渲染、继续对话或手工修改 SlideML
```

普通课件只有在主题结果通过校验且快照成功发布后才进入分析完成状态。快照目录通过加载和 Theme 2.0 复核后跳过主题 Agent，直接恢复等价工作台。

## 二、打开并加载课件

### 1. 目录识别

首页的“打开课件”入口接受普通 Markdown 导出目录和主题快照 v2。普通目录根目录包含 `Courseware.json`；快照目录还包含 `CoursewareThemeAnalysis.json`。存在快照标记但内容损坏、版本不受支持或校验失败时，系统明确加载失败，不回退普通课件分析。快照 v1 被明确拒绝。

### 2. 加载阶段完成全部导出格式校验

`CoursewareFolderLoader` 在读取阶段完成课件导出格式校验，失败不会进入主题分析：

- `Courseware.json` 存在、可解析且 `ExportVersion` 为 `1`；
- 页面列表非空，`SlideCount` 与列表数量一致；
- `SlideIndex` 从 `0` 连续且与清单顺序一致；
- `SlideId` 非空且唯一；
- 页面宽高为有限正数；
- Markdown 和截图路径采用规定的 `Slides/SlideXXX` 命名且不能越界；
- Markdown 存在、以 `## 页面信息` 开始，且其中 Id、1-based 页码和尺寸与清单一致；
- `ResourcesFile` 存在且路径安全；
- 资源索引是数组，资源 ID 唯一，类型仅允许 `image`、`audio`、`video`，文件名不能越界。

Markdown、清单或资源索引格式错误是阻断错误。截图或资源实体文件缺失只形成 Warning，课件仍可加载。加载成功后形成 `CoursewareInputPackage`，界面建立课件会话和真实缩略图。

## 三、普通课件的主题分析

### 3. 样式使用汇总

`CoursewareStyleUsageSummaryBuilder` 只从代码块之外的结构化样式元数据汇总字体、字号和颜色；同值合并计数，按次数降序和稳定值排序，每类最多 12 项，并支持取消。这些数据只供参考，不是必须继承的限制，也不会构造默认主题。

### 4. 主题 Prompt 逐字拼接

`CoursewareThemeAnalysisPromptBuilder` 写入固定任务说明和样式参考后，按页面稳定顺序逐字追加每页 `MarkdownText`。不执行 Trim、摘要、转义、路径替换、身份重写或内容裁剪；页面之间只插入 `\n\n---\n\n`。程序不附加截图、文件路径、页数、资源统计或布局预分析。

### 5. 独立主题 Agent 与三轮闭环

`CopilotCoursewareThemeAgent` 为每次分析创建独立会话，只暴露 `submit_courseware_theme_analysis`。首轮发送完整主题 Prompt，每轮发送前执行上下文预算检查。未调用工具或提交校验失败时，在同一会话发送只含问题列表的短修复 Prompt，不重复整份 Markdown。最多三轮，第三轮仍失败时报告最近问题；取消直接向上传播。

### 6. Theme 2.0 契约

主题结果仅包含：`SchemaVersion=2.0`、`ColorSuggestions`、`Fonts.Chinese`、`Fonts.Western`、`Style`、四边 `SafeArea` 比例、`SpacingAndVisualEffects`、`LayoutPrinciples`、`CoverPageSlideMl` 和 `ContentPageSlideMl`。不包含旧主题兼容对象、默认主题或页面分类映射。

### 7. 字段和真实 SlideML 校验

`CoursewareThemeValidator` 汇总字段与 SlideML 错误。两份 SlideML 都必须通过完整 XML 文档边界、共享 Schema 标签/属性/父子层级、流式协议禁用、资源 ID、可见文本和固定高度检查，并使用课件第一页实际画布执行生产解析、布局和 WPF 渲染。越出画布、越出父容器、裁剪和内容溢出等 Warning 是阻断问题。WPF 渲染统一调度到可用 STA Dispatcher；应用 Dispatcher 不存在或已关闭时使用专用后台 STA Dispatcher。

## 四、主题快照 v2

### 8. 保存和目录

普通课件分析成功后先保存并回读快照，再提交界面。目录名为 `CoursewareThemeAnalysis_yyyyMMdd_HHmmss_fff`，重名追加后缀。写入使用临时兄弟目录，验证成功后原子重命名；失败或取消时清理半成品。

```text
CoursewareThemeAnalysis_20260722_034447_123/
├── CoursewareThemeAnalysis.json
├── Courseware.json
├── Theme/
│   └── Theme.json
├── Slides/
│   ├── Slide000.md
│   ├── Slide000.jpg
│   └── ...
└── Resources/
    ├── Resources.json
    └── ...
```

v2 清单只包含 `Version: 2`、`CreatedAt`、固定根目录 `Courseware.json` 的 `CoursewareManifestFile`，以及指向 `Theme/Theme.json` 的 `ThemeFile`。快照复制全部 Markdown、存在的截图、资源索引和存在的资源文件；缺失文件不创建占位。

### 9. 快照恢复

加载时验证版本和路径边界，使用普通加载器重新校验课件副本，读取 `Theme/Theme.json`，并用首张页面实际画布重新执行 Theme 2.0 字段与真实 SlideML 校验。成功后跳过主题 Agent，直接创建等价工作台；不恢复主题分析对话或事件。Markdown 可在快照内修改，只要仍符合导出格式就按当前内容恢复，不做内容哈希比对。

## 五、主题结果与重新分析

主题分析期间固定显示分析对话并保留完整 Copilot 消息；成功后展示配色、中西文字体、风格、安全区、间距视觉效果、版式原则及两份参考 SlideML。失败或取消保留已加载课件和重试入口。快照保存失败时不得提交结果或创建工作台。

重新分析创建全新主题会话和新快照。已有页面工作台对象及页面状态保留；新主题只影响尚未开始且未被用户编辑的未来首轮草稿，已开始页面会话不被静默覆盖。

## 六、真实页面美化工作台

### 10. 页面状态与运行时

每个真实页面拥有独立身份、画布、Markdown、标题摘要、截图状态、输入附件、运行时、聊天会话、生成状态、SlideML 和预览。运行时按需懒加载，进入工作台只初始化当前选中页。切页不取消已经开始生成的其他页面任务，取消只作用于对应页面。释放后的迟到初始化结果不能重新挂接。

模型初始化失败时保留同画布本地渲染 fallback：AI 生成禁用，但合法 SlideML 可重新渲染。

### 11. 首轮页面 Prompt

`CoursewareSlidePromptBuilder` 生成用户可见的结构化首轮 Prompt，包含用户要求、当前页身份与完整 Markdown、Warning、实际引用资源、前后页标题摘要、截图存在与实际附件边界、完整未经缩放或截断的 Theme 2.0，以及两份完整参考 SlideML。所有页面接收同一主题对象，但不预先指定页面类型。

统一发送复用同一页面会话。发送期间用户修改输入时，成功回调不得覆盖新草稿；首轮取消后保留可见草稿和附件并允许重试。手工修改 SlideML 后必须先本地重新渲染，未渲染内容不能直接统一发送。

## 七、取消、并发和状态保留

- 打开新目录会取消旧加载或主题流程，并阻止旧结果写入新会话；
- 主题 Agent、样式汇总、快照保存和加载均接受取消令牌；
- 同一主题 Agent 的并发分析隔离会话、工具实例和提交结果；
- 不同页面可并发生成，单页取消不影响其他页面；
- 异步命令暴露可等待执行任务并默认阻止重复并发启动；
- 分析页与工作台往返、切页和重新分析保留已建立页面状态；
- 测试使用硬超时和可等待同步点，不依赖 `Sleep`。
