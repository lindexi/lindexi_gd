# FantasticCanvas 矩形放置独立实验

独立的矩形容器放置算法与可视化实验，解决方案包含 Lib、WPF、Tests 三个项目。

## 环境与运行

需要 .NET 10 SDK。Lib 和 Tests 面向 `net10.0`，WPF 面向 `net10.0-windows`，运行可视化界面需要 Windows 桌面环境。单元测试使用 MSTest 4.0.1。

用 Visual Studio 打开本目录解决方案，将 WPF 设为启动项目。构建整个解决方案；Tests 可单独运行且不依赖 WPF。

## 算法的实际定义

- 所有坐标为 double 世界坐标，Y 轴向下；输入提前确定最终宽高。不缩小、不旋转容器。起点指**新容器左上角**等于原始视口中心，而不是容器中心。
- 新容器必须全矩形包含在当前逻辑搜索范围内；自动放置与每个已有容器之间至少保留 10 世界坐标单位的间距（`Placement.MinimumMargin`），恰好 10 可用。仅将障碍向四周扩张 10，禁止新容器与扩张障碍内部相交；新容器实际尺寸不变，不要求距视口或逻辑范围边缘 10。
- 以下障碍边界均指扩张后的边界。不采用像素扫描或固定行距，而采用几何事件行：中心 Y、范围顶部、范围底部减新高度，以及每个障碍的顶部减新高度、底部。过滤到允许的左上角 Y 区间并去重。
- 中心行优先；中心以下候选按 Y 递增编号，下1、下2……；中心以上按 Y 递减编号，上1、上2……。搜索顺序为中心、下1、上1、下2、上2……；一侧耗尽后继续另一侧。**行距由几何边界决定，不是等距离**；交替的是行序号，不保证上下距离相等。
- 每行 X 候选同理：中心 X、范围左右允许端点、障碍左边减新宽度、障碍右边。先搜索 X≥中心的候选（从小到大），再搜索 X<中心的候选（从大到小）。即中心向右完整搜索完，才向左搜索，不按左右最近距离混排。
- 障碍对新左上角构成开禁区 `(left-width,right) × (top-height,bottom)`。可行区域由这些边界切分；非空空位可以移至边界候选而不进入禁区，所以无需枚举中间像素。包括扣除间距后的狭窄空位和恰好满足 10 间距的位置。实现枚举候选笛卡尔积并检查碰撞，优先保证简单、确定与完整；每轮最坏 O(n³)，空间 O(n)，不是大规模空间索引方案。
- 只有当前整范围所有候选失败，才将宽、高**分别乘以 1.2**，以原始视口中心重新计算逻辑范围并重试；不存在人为扩展次数上限。`Placement.Find(viewport, size, occupied)` 仅返回新容器左上角世界坐标 `PointD`，可在实际视口外；调用方使用返回点和原始 `size` 合成矩形，不提供搜索范围或扩展次数等诊断接口。每次添加从当时真实视口重新开始，不复用上次范围，不自动修改视口或已有容器。
- 输入列表先复制；不排序或修改调用方数据。拒绝 null、非有限坐标、非正/非有限尺寸；边界或障碍扩张运算溢出、double 精度导致正尺寸或 10 单位间距无法表现、扩展不再增长时抛 OverflowException，不静默忽略、不以容差允许重叠。数学完备性基于实数几何；double 极限下不承诺任意精度放置。

## 界面

仅矩形、标签和三个添加按钮：A4 竖向 210×297、横向课件 480×270、宽多页课件 1440×270（实验世界单位，不读取文件）。Ctrl+滚轮围绕鼠标缩放，倍率限制 5%～800%；右键拖动画布平移；左键拖动命中的最上层容器，直接更新位置，手动拖动允许重叠、不限制间距、不自动避让或重新布局。后续自动添加仍避让所有已有容器，包括手动形成的重叠障碍。

世界→屏幕为 `screen = world × scale + translation`；反变换用于鼠标、拖动和计算真实视口。真实视口仅为底栏上方画布，底栏不参与放置。仅用蓝色虚线绘制真实可视边界，随世界变换绘制并受画布裁剪；状态只显示容器数和缩放。内部逻辑范围扩大到屏幕外不会自动缩小视图。添加大容器后可手动缩放/平移查看。异常在界面显示，不吞错。

## 分配回归

每次搜索复制障碍并分配两个 `2*n+3` 候选数组，跨扩展复用；每轮每轴原地过滤、排序、去重一次，按索引遍历并直接检查碰撞，不改变搜索顺序、异常约定或每轮最坏 O(n³) 复杂度。`Tests/ReferencePlacement.cs` 保留旧算法及测试内部的 `ReferenceResult` 作为对照，生产结果只比较左上角坐标；扩展倍率和中心通过边界障碍及预期落点验证，不反射私有实现。新增测试覆盖确定布局、512 种网格、混合尺寸序列及数值异常；分配测试先预热 32 次，再累计 100 次当前线程分配，以 `1024+96*n` 字节/调用的宽松预算回归，通过 TestContext 输出新旧实测值。测量使用泛型委托兼容旧引用类型结果和新 `PointD` 值类型，不对返回点装箱。专用测试默认生成 TRX 报告，成功测试的测量数据也可查看；不使用耗时断言。

## 验证范围

使用独立解决方案 Release 构建和 Tests 的专用测试入口验证；具体结果见交付记录。未做 Windows 桌面实际鼠标交互或截图验证，不能以编译和计算测试代替桌面验收。大规模障碍性能和任意精度计算不在本实验范围。
