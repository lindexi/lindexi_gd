有效 `YY-Thunks/objs/<arch>/YY_Thunks_for_Win7.obj` 缺失；前任务未找到官方流程所需 LibMaker。YY Build.cmd 的对象需要 LibMaker FixObj，不能将普通 cl 生成对象冒充成品。没有安装、下载执行不明工具；普通 build 缺对象仍拒绝，只有 baseline 不添加 OBJ。发布 manifest 明确 YYThunksIntegrated=false。

## 官方入口与注入依据

runtime/build.cmd 转交 eng/build.ps1，使用官方子集还原、编译与版本生成。完整模式再调用官方 installer/pkg/sfx 下 Runtime.CoreCLR 与 Bundle 项目，PublishReadyToRun=false，不组装SDK。PowerShell参数使用 ArgumentList + EncodedCommand，计划保存解码脚本供审计。

Windows corehost 不转发通用 CMakeArgs，因此用 CMAKE_TOOLCHAIN_FILE 环境初始化，再设置 CMAKE_PROJECT_INCLUDE；三个项目为 CoreCLR、LibsNative、corehost。顶层 DEFER 递归审核原生最终链接目标，baseline不加YY。每次清除所选架构配置生成 CMakeCache/cmake_cmd_line，避免继承旧注入。官方版本目标与模板负责生成资源，不把未生成版本文件当静态阻塞。VS/CMake/Ninja来自已安装工具；官方 bootstrap 的仓库本地SDK依赖与产品输出严格分离。
