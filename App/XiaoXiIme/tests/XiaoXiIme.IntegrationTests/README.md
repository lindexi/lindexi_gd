# XiaoXiIme.IntegrationTests

小希输入法系统级集成与冒烟测试项目。托管测试覆盖 Host IPC 基础闭环、Host/UI 状态查询、候选窗状态映射、显示/隐藏、固定每页 9 项的分页、末页页码、跨页选择、唯一高亮和锚点占位。IPC 闭环会通过 `hostBaseDirectory` 加载测试布局中的生产 package，并覆盖全拼 `xiaoxiaimuyi` 与小鹤 `xnxiaimuyi` 连续输入后空格上屏 `XiaoXiIme`。`SetComposition` 可整串替换全拼 `xiaoxiaimuyi`，不会自动提交缩写 `xx`。`QueryConversionList` 可查询全拼 `xiaoxiaimuyi` 而不改变当前组合。`QueryReverseConversionList` 可把 `XiaoXiIme` 反查为 `xiao xi ai mu yi` 而不改变当前组合。IMM `ImeConversionList(GCL_REVERSELENGTH)` 只返回该反查缓冲所需字节数。`RegisterWord` 可写入共享用户词典并在新宿主中持久化，不改变当前组合。`ImeConfigure(IME_CONFIG_REGISTERWORD)` 走同一注册路径。同一宿主上两个 `ImeSessionId` 可分别组合 `xiaoxiaimuyi` 与 `aimuyi`；空的 `GetSnapshot`/`GetUiState` 回退到最近活动会话。`ResetSession` 只丢弃指定会话，第一会话仍组合 `xiaoxiaimuyi`。`ImeHostBridge`、`ImeModuleRuntime` 与完整 IMM 路径也覆盖同一提交：`ImeProcessKey` 先吃键，再经同一 HIMC 走 `ImeToAsciiEx` 把 `GCS_RESULTSTR` 写回。`ImeSetCompositionString` 走同一 HIMC 写回组合串。`ImeSelect`/`ImeSetActiveContext` 取消组合并复位该会话；`NotifyIME` 在同一 HIMC 上取消组合、完成候选、选择当前页候选或回退提交 reading；`ImeDestroy` 复位全部会话。自包含 `XiaoXiIme.IntegrationTestHost` 会从负载 `app/host` 解析全拼 package；该目录缺失时立即失败，不会静默改用最小回退词典。管理员沙箱或可还原 VM 中的真实安装、HKL 激活、HIMC 打开、`SendInput` 自动注入 `xx` 和单个 EDIT 精确上屏“小希”的基础冒烟由 CLI 的 `integration-run --skip-tsf` 调用，不属于普通 `dotnet test`。当前项目仍缺正式词库高层按键与候选选择、多应用/多会话、完整组合交互、生命周期/异常恢复、长时间输入，以及 x86/x64 目标应用矩阵测试。
