# XiaoXiIme.ImeModule.Tests

小希输入法 IME 模块仿真测试项目。职责：在不注册系统输入法的情况下测试 IME 模块内部逻辑、按键输入、组合状态和提交结果。当前覆盖：按键转换、导出托管入口、异常保护、IMM 内存布局、候选/GUIDELINE/私有区写回、Host Bridge 本地降级，以及双 package 布局下 `ImeHostBridge`/`ImeModuleRuntime` 与完整 IMM 路径。`ImeProcessKey` 与 `ImeToAsciiEx` 共用同一 HIMC：先吃全拼 `xiaoxiaimuyi` 或小鹤 `xnxiaimuyi`，再写回组合串、候选和 `GCS_RESULTSTR`，空格上屏 `XiaoXiIme`。`ImeSetCompositionString(SCS_SETSTR)` 整串替换全拼 `xiaoxiaimuyi` 或小鹤 `xnxiaimuyi` 并写回 HIMC，空串清空组合且不写结果串。`ImeConversionList(GCL_CONVERSION)` 按源串查询全拼 `xiaoxiaimuyi` 或小鹤 `xnxiaimuyi`，把 `CANDIDATELIST` 写入调用方缓冲，不改变当前 HIMC 组合。`ImeConversionList(GCL_REVERSECONVERSION)` 把 `XiaoXiIme` 反查为规范 reading `xiao xi ai mu yi`，同样不改变当前 HIMC 组合。`ImeConversionList(GCL_REVERSELENGTH)` 返回该反查缓冲所需字节数且不写目标缓冲。`NotifyIME(NI_SELECTCANDIDATESTR)` 使用 Windows SDK 值 `0x0012`。`ImeEscape(IME_ESC_QUERY_SUPPORT)` 报告支持 `IME_ESC_IME_NAME`，`ImeEscape(IME_ESC_IME_NAME)` 写入 `XiaoXi IME` 显示名，不改变当前组合。`ImeRegisterWord`/`ImeUnregisterWord`/`ImeGetRegisterWordStyle`/`ImeEnumRegisterWord` 写入共享用户词典并报告用户样式，不改变当前 HIMC 组合。`ImeConfigure(IME_CONFIG_REGISTERWORD)` 用 `REGISTERWORD` 走同一注册路径，不打开配置 UI，也不改变当前 HIMC 组合。两个独立 HIMC 可分别组合 `xiaoxiaimuyi` 与 `aimuyi`。`ImeSelect(select=0)` 与 `ImeSetActiveContext(active=0)` 取消组合、清空 HIMC 并复位该会话；`NotifyIME(CPS_CANCEL)` 取消组合但不丢会话；`NotifyIME(CPS_COMPLETE)` 提交当前候选；`NotifyIME(NI_SELECTCANDIDATESTR)` 提交当前页指定候选；`NotifyIME(CPS_REVERT)` 提交 reading；`ImeDestroy` 复位全部会话。
