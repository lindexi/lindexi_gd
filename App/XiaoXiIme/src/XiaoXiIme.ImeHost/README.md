# XiaoXiIme.ImeHost 小希输入法外部服务进程。职责：接收 ImeModule 的 IPC 请求，按 `ImeSessionId` 维护独立输入上下文，调用词库服务，协调候选窗、状态窗、日志和健康检查。默认加载宿主目录下的全拼 package；设置 `XIAOXIIME_INPUT_SCHEME=xiaoheDoublePinyin` 时加载同级 `XiaoXiIme.DictionaryPackages/xiaoheDoublePinyin`。测试和诊断可通过 `hostBaseDirectory` 指向安装布局而不改 `AppContext.BaseDirectory`；集成测试宿主会解析负载 `app/host` 目录。双 package 布局下，全拼连续输入 `xiaoxiaimuyi`、小鹤连续输入 `xnxiaimuyi` 后空格上屏 `XiaoXiIme`；`ImeHostBridge` 经 IPC 转发同一提交路径；`ImeProcessKey` 与 `ImeToAsciiEx` 共用同一 HIMC，先吃键再把提交写成 `GCS_RESULTSTR` 写回。HIMC 映射为独立会话后，两个输入上下文可分别组合 `xiaoxiaimuyi` 与 `aimuyi` 而不互相覆盖；空的 `GetSnapshot`/`GetUiState` 回退到最近活动会话。`XiaoXiIme.ResetSession` 按会话删除 `ImeContext`，空会话回退最近活动会话，`ResetAll` 清空全部并把最近活动会话打回 `default`。`ImeSelect(select=0)` 与 `ImeSetActiveContext(active=0)` 取消组合后复位该 HIMC 会话；`NotifyIME(NI_COMPOSITIONSTR)` 在同一 HIMC 上取消组合、完成候选或回退提交 reading，其中 `CPS_CANCEL` 不丢会话；`NotifyIME(NI_SELECTCANDIDATESTR)` 提交当前页指定候选；`ImeEscape(IME_ESC_IME_NAME)` 返回 `XiaoXi IME` 显示名且不改会话组合；`XiaoXiIme.QueryConversionList` 可按源串查询候选，也可按 `ImeConversionListKind.ReverseConversion` 把 `XiaoXiIme` 反查为 `xiao xi ai mu yi`；IMM `ImeConversionList(GCL_REVERSELENGTH)` 只返回该反查缓冲所需字节数，不改会话组合；`XiaoXiIme.RegisterWord` 注册、注销或枚举共享用户词典且不改会话组合；`ImeConfigure(IME_CONFIG_REGISTERWORD)` 走同一注册路径且不改会话组合；`ImeDestroy` 复位全部会话。`ImeHostStatus.DictionaryInputScheme` 报告实际加载方案，加载失败仍使用明确标识的最小回退词典。`ImeUiState` 用 `IsUsingFallbackDictionary` 报告该降级，`IsHostUnavailable` 仅表示桥接不可达。`install`/`integration-run` 会在进程启动后等待 `GetHostStatus` 报告运行中。
