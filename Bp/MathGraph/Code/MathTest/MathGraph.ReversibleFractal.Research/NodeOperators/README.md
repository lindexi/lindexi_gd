# 有序节点算子与正反五点 DAG

本目录包含独立的 .NET 9 核心库 `NodeOperators/NodeOperators.csproj` 和 MSTest 项目 `NodeOperators.Tests/NodeOperators.Tests.csproj`（Microsoft.NET.Test.Sdk 17.12.0，MSTest 3.6.4）。测试项目仅引用本目录下的核心库，核心库不引用 MathGraphs、WPF 或其他研究项目。未改动解决方案，构建产物留在各项目下。

## 算子与接线

每个节点是有序实数端口上的向量映射 `z[j] = b[j] + Σ_i W[j,i] x[i]`、`y[j] = φ(z[j])`。每个输出行对应独立权重和偏置，参数布局为 `[W[j,0], …, W[j,n-1], b[j]]`，按输出号逐行拼接。参数块按声明的节点列表顺序拼接，不按求值顺序。使用相同激活不代表共享参数；混用是按叶选择 Identity 或 Tanh，不改变接线或逆传引擎。

`OperatorGraph` 的 `OperatorNode.Inputs[i]` 是输入端口 `i` 的唯一来源；`SourcePort(-1,i)` 指外部输入，其余来源按节点号和输出号定位。一个来源可被多个消费者使用，也可重复暴露为图输出；图输出列表定义边界的顺序。构造时校验端口和节点入参长度、编译拓扑序并拒绝环。`Forward` 返回边界值，`Differentiate` 还返回输入和参数的梯度。

`FullCross.Create` 独立复现正反模板的接线约定：

| 模板 | 固定内部边顺序 | 有序边界输入 | 有序边界输出 |
| --- | --- | --- | --- |
| 正向 `2→1` | `A→C, A→D, B→C, B→D, C→E, D→E` | `A, B` | `E` |
| 反向 `1→2` | `C→A, D→A, C→B, D→B, E→C, E→D` | `E` | `A, B` |

按表顺序分配每个节点的内部输入/输出端口号，然后分配边界端口号。例如正向 A 的输出 0 连 C、输出 1 连 D；反向 C 的输出 0 连 A、输出 1 连 B。根使用正向模板。展开路径 `A` 对应反向替换，`C` 对应正向替换；可同时展开两端或指定 `A/A` 等后代（必须包含其展开祖先）。容器不计算、不占参数；外部连接递归解析到实际叶端口。FullCross 的节点列表是 A 到 E 的深度优先叶序。反向指模板的边反转，不是求函数逆，也不是反向传播本身。

## 反传为什么成立

对固定种子 `s`，求标量 `L = s·Forward(x,p)` 的梯度。先在图输出源端口上用 `+=` 加种子，再按逆拓扑序处理节点。处理某节点时，它的所有下游消费者均已处理；其输出端口的伴随量因此等于直接种子与所有使用者贡献之和。局部链式法则给出：

- `δ[j] = adj(y[j]) · φ′(z[j])`，Identity 的导数为 `1`，Tanh 为 `1−y[j]²`；
- `∂L/∂b[j] = δ[j]`，`∂L/∂W[j,i] = δ[j]·x[i]`；
- 对每个输入来源累加 `δ[j]·W[j,i]`。同一来源多次使用、节点具有多个输出、图输出指向中间值或同一端口时，都不覆盖既有贡献。

由逆拓扑归纳可得：在实数精确运算、有限无环接线和独立参数块的前提下，结果是整个图的向量–雅可比积（等价于 `Jᵀs` 的列向量表示）。证明只使用局部导数，不要求节点激活一致。浮点实现不保证与实数结果逐位相同。

## 验证与复现

从本目录运行：

- `dotnet build NodeOperators/NodeOperators.csproj`
- `dotnet test NodeOperators.Tests/NodeOperators.Tests.csproj`

本次验证：核心构建 0 警告、0 错误；MSTest 17 项全部通过，无失败或跳过。

- **解析检查**：非对称 Identity 基础图在输入 `(0.5, −1)` 下，A/B 的两路值分别为 `(2, 1.5)` 和 `(−4, 3)`，C/D 值为 `19` 和 `5.5`，最终输出 `35.5`。从 E 回传，A 两端口收到 `(10, 3)`、B 收到 `(−4, −4)`，故输入梯度为 `(17, −16)`；逐项检查权重和偏置梯度。Tanh 双输出节点用 `sech²(z)` 作为独立解析导数。另一手算 DAG 逆序声明节点，同时覆盖重复绑定、多个消费者与重复输出种子。
- **接线检查**：用独立显式算式校对同时展开 A/C 的混合图，避免仅用同一前向实现的差分误把接线错误判为正确。另检查非法端口、环和缺失展开祖先。
- **中心差分**：在同一组确定性非对称输入和参数上，每次仅改动一个输入、权重或偏置，用 `[L(v+h)−L(v−h)]/(2h)` 与反传比对。`h=10⁻⁵`，允许误差 `2×10⁻⁸·(1+|差分结果|)`，以同时容纳近零项和较大梯度的浮点误差。覆盖基础图和双展开图的全 Identity、全 Tanh、混合激活，以及单正向、单反向、嵌套展开的混合图；另用带正负种子的多输出 DAG 核对 `s·y`，包括直接暴露外部输入的情况。差分在平滑区域有二阶截断误差，但过小步长会放大舍入误差；这里只检验指定样点。

## 结论边界

研究支持的是：两类接线可由同一有序 DAG 引擎执行，同构或混用激活都可按同一反传规则求输入和参数梯度。它不支持某种激活更优、展开保持原函数、逆模板可逆、训练更快或更易收敛等主张。无训练数据、优化器、随机种子对照或性能基准；不覆盖 Tanh 饱和区的高精度、非有限数、参数共享或有环图。递归模板生成受栈和内存限制。
