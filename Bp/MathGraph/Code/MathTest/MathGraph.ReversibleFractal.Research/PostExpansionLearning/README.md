# 保函数展开后的支路学习

**结论：展开时输出不变，不等于新增参数的梯度为零。** 硬屏蔽让所有新增参数的梯度恒为零；可训练零门可以先开门、再更新支路权重；非零门下的差分抵消允许两个独立支路权重在第一步就更新。是否实际更新还取决于残差、可达输入和参数是否绑定。

## 有序五点接线

沿用相邻 `FunctionMorphism` 研究的五点模板，核心没有项目引用，也不依赖 WPF。端口从 0 编号；反向交换每根线的源输出和目标输入（包括端口编号），不是求函数逆。

| 正向源输出 | 正向目标输入 | 反向源输出 | 反向目标输入 |
| --- | --- | --- | --- |
| A.0 | C.0 | C.0 | A.0 |
| A.1 | D.0 | D.0 | A.1 |
| B.0 | C.1 | C.1 | B.0 |
| B.1 | D.1 | D.1 | B.1 |
| C.0 | E.0 | E.0 | C.0 |
| D.0 | E.1 | E.1 | D.0 |

- **2→1**：外入 `(A.0,B.0)`，外出 `E.0`。A、B 各复制自身输入；C 对收到的 `(u,v)` 返回 `u+gp(u−v)²`，D 返回 `v−gn(u−v)²`；E 保留原父算子 `f(c,d)=c+d`。两条平方支路各在一个子点。
- **1→2**：外入 `E.0`，外出 `(A.0,B.0)`。E 保留原父算子 `s(t)=(t,−2t)`，C、D 分别复制 E 的两个输出；A、B 各按接线收到 `(u,v)`。A 返回 `u+[gpu²−gn(v/2)²]`，B 返回 `v+[gp(v/2)²−gnu²]`。各输出点的两条支路分别读取不同输入端口，`p,n` 跨两个输出点共享；固定系数 `−2` 与 `/2` 使两个特征在 E 的可达集合上相等，并非假定任意 `(u,v)` 都抵消。若另行训练 E，这个可达集合条件可能失效。

其中 `g` 是标量门，`p,n` 是独立优化参数；硬屏蔽用与 `g` 无关的常数零替换有效门。只有 `g,p,n` 参与优化。实现通过六根线逐点传值，不以化简后的边界式代替前向图。

## 保函数与梯度证明

在实数上令 `k=g(p−n)`。从接线代入，正向输出 `x+y+k(x−y)²`，反向输出 `(t,−2t)+kt²(1,1)`。因此任一未屏蔽模块在整个输入域保函数当且仅当 `k=0`；硬屏蔽则恒保函数。正向两支路在 E 才抵消，数学等价不保证浮点逐位一致，特别是大相消量可能使路由值丢失精度。测试中的保函数输入采用小的二进制可精确表示数值。

取半平方误差，残差定义为「预测减目标」。令 `S = r(x−y)²`（正向），或 `S = (r₀+r₁)t²`（反向），则 `S=∂L/∂k`。链式法则给出下表；批量训练时 `S` 换成样本 `S` 的和（或均值，与所选损失归约一致）。

| 保函数初始化 `(g,p,n)` | `∂L/∂g` | `∂L/∂p` | `∂L/∂n` | 首步行为 |
| --- | ---: | ---: | ---: | --- |
| 硬屏蔽 `(1,1,0)` | 0 | 0 | 0 | 任何残差都不能使支路解封 |
| 可训练零门 `(0,1,0)` | `S` | 0 | 0 | `S≠0` 时先更新门 |
| 非零差分抵消 `(1,1,1)` | 0 | `S` | `−S` | `S≠0` 时两权重立即向相反方向更新 |
| 对称零门 `(0,1,1)` | 0 | 0 | 0 | 普通梯度下降停在初始化点 |

一般形式为 `((p−n)S, gS, −gS)`。非零门不是非零梯度的充分条件：正向 `x=y`、反向 `t=0` 都让特征为零；反向 `r₀=−r₁` 时即使损失非零，残差也与支路唯一可改变的方向 `(1,1)` 正交；批量中各样本贡献也可相消。相等初始化不等于绑定：若强制 `p=n=w`，则 `∂L/∂w=gS−gS=0`，转而沿共同方向更新不能解除抵消；独立权重允许沿差分方向离开。这个模型只暴露一个有效系数 `k`，并不表明所有新增自由度都可学习。

## 确定性实验与验证范围

在本目录运行 `dotnet test Tests/MathGraph.PostExpansionLearning.Tests.csproj`。核心与测试均为 `net9.0`；Microsoft.NET.Test.Sdk 为 `17.12.0`，MSTest TestAdapter 和 TestFramework 均为 `3.6.4`。不加入共享解决方案，构建产物留在子项目目录。本次实际运行：退出码 0，28 个用例通过、0 个失败、0 个跳过。

- 首步测试在两种模板上各比较四组解析梯度；独立的中心差分以 `h=10⁻⁶` 和绝对容差 `10⁻⁸` 检查两种模板各五组参数（三个参数逐一扰动，包括非初始化点）。另检查非对称实际端口值、零特征和反向残差正交。
- 多步对照使用同一模板内同一目标、同步梯度下降、步长 `1/16`，固定单样本全梯度，共 24 步，无随机种子或优化器状态。正向在 `(1,0)` 拟合 `2`，反向在 `t=1` 拟合 `(2,−1)`。下表报告测试断言的观测范围，不将上界写成测得的精确终值。

| 初始化 | 正向首步后的 `g`, `p−n` | 反向首步后的 `g`, `p−n` | 第 24 步半平方损失（正向 / 反向） |
| --- | --- | --- | --- |
| 硬屏蔽 | `1,1` | `1,1` | `0.5 / 1`，参数不动 |
| 可训练零门 | `1/16,1` | `1/8,1` | 两者都 `<0.01` |
| 非零差分抵消 | `1,1/8` | `1,1/4` | 两者都 `<0.01` |
| 对称零门 | `0,0` | `0,0` | `0.5 / 1`，参数不动 |

各对照逐步检查损失不升；可训练零门的 `p` 在第一次更新后的梯度分别是 `−15/256` 与 `−7/32`，因此权重从第二次更新才开始动。证据只覆盖这两个固定仿射父算子、允许平方支路的单层展开、指定数据与步长；未验证多层嵌套、父算子同时训练、统一激活约束、不同优化器或多样本上的泛化，也未实现通用收起检测或近似投影。

## 拓扑恢复不等于数值恢复

把五个点缩回一个同签名节点，可以还原边界端口的连线，但参数训练后，单个**同类仿射节点**可能无法复现边界函数。以非零差分抵消开始，按上文各取一步：正向得 `k=1/8`，反向得 `k=1/4`。正向固定 `y=0` 的切片成为 `x+x²/8`，反向第一端口成为 `t+t²/4`。在 `−1,0,1` 上计算二阶差分 `F(−1)−2F(0)+F(1)`，分别为 `1/4` 和 `1/2`（测试精确比较这两个值）。任一仿射函数的二阶差分都为零，所以即使允许重新拟合父节点的全部仿射参数，也不能在这三个点上同时精确匹配，更不能在整个域精确收起。保留原父算子可恢复展开前的函数，但会丢弃学习结果；扩大父算子类别或接受近似是不同的操作。
