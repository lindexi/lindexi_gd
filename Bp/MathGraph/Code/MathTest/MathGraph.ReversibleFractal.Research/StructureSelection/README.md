# 正反五点结构选择研究

本目录包含独立的 .NET 9 控制台核心、MSTest 项目和 WPF 可视化项目。WPF 单向引用本目录的核心；核心和测试不依赖 WPF。各项目均不加入解决方案。局部 `Directory.Build.props` 隔离继承的构建输出设置。

## 复现

在本目录运行（需要 .NET 9 SDK）：

- `dotnet test Tests/MathGraph.StructureSelection.Tests.csproj`
- `dotnet run --project Core/MathGraph.StructureSelection.csproj -c Release`
- `dotnet run --project Core/MathGraph.StructureSelection.csproj -c Release -- --json`：输出逐配对记录，含选点、方向、梯度信号、批次指纹、容量、成本、验证分和测试误差。

## WPF 可视化

项目：`Wpf/MathGraph.StructureSelection.Wpf.csproj`（`net9.0-windows`）。在 Windows 上从本目录执行 `dotnet build Wpf/MathGraph.StructureSelection.Wpf.csproj` 即可单独构建，不会打开窗口。如需手动查看，可用 `dotnet run --project Wpf/MathGraph.StructureSelection.Wpf.csproj` 启动（需要 .NET 9 Desktop Runtime）。

点击「运行核心实验」会在后台调用同一个 `Experiment.Run()`；无需先运行控制台或准备结果文件。结束后按任务、种子和检查点选择配对。不展开、随机展开和梯度展开并排显示，两种数据集的 MSE 使用同一从零开始的标尺。窗口标出验证后保留的策略、保留分数、选点和方向；测试集仅用于评估。预算区域列出数据集大小、共享批次指纹、候选训练样本及端口访问数和梯度选点的额外成本。

## 拓扑和协议

根图是 `A→C,A→D,B→C,B→D,C→E,D→E`，并有 `S0→A,S1→B,E→T` 三条边。`2入1出` 叶展开为该正向模板；`1入2出` 叶展开为六条内部边全部反向的模板，输入接 E，输出按 A/B 的顺序接回。替换删除原叶、加入五个真实计算点和六条内部边；外部边保留对应端口，不添加适配点或计算容器。支持递归替换，但实验只考察单次展开。反向是边反向，不是函数求逆。

每个输出端口独立学习 `z + a*tanh(z)`，其中 `z` 是该叶输入的仿射组合。前向沿真实拓扑边传值，梯度逆拓扑逐端口累加。展开时 C 继承原叶算子，其他子点用线性路由保持函数；D 支路的接收系数初始为零，但其值无需为零，接收系数可被梯度更新。未替换参数原样复制。初始预测逐样本核验，以排除展开当下的函数跳变；不假设展开后梯度或优化轨迹相同。

- 两个无噪声任务，输入独立均匀采样于 `[-1,1)`。`affine`：`0.25 + 0.65*x0 - 0.35*x1`；`mixed` 在其上加 `0.65*tanh(3*x0*x1) + 0.4*tanh(4*x0 - 2*x1)`。每任务每种子有 128/256/1024 个训练/验证/测试样本，各用不同的 SplitMix64 流。两个任务同种子共享坐标和初始化，不能当作独立重复。种子：11、23、37、53、71、89、107、127。
- 在未展开轨迹的第 0、64、256 个 SGD 更新处冻结同一检查点。三个分支分别继续不改图、均匀随机选一个合法实际叶、选择训练集上参数组梯度 RMS 最大的合法叶（并列按路径序）。三分支各做 64 次 SGD，学习率 0.025，每批有放回抽 16 例；每对照共享完全相同的下标和顺序，独立于预训练批次和选点随机流。不因随机与信号选到同一点而重抽。检查点之间不延续任何候选分支。
- **保留分数独立于选点信号**：`(继续训练验证 MSE - 候选验证 MSE)/max(继续训练验证 MSE, 1e-12) - 0.01 - 0.001*新增参数数`。不改图候选固定为 0，只有得分严格为正才展开。当前两方向均增加 20 参数，常规阈值即验证 MSE 相对下降超过 3%。同分按继续、随机、信号的顺序处理；同点通常同分，因此不能用保留标签的次数单独比较两种选点策略。首次接受是沿未展开轨迹最早达标的检查点，不是逐轮扩树的结果。测试集在每对的保留决策锁定后评估，不参与选点、保留或改设阈值。

## 成本和限制

2 任务 × 8 种子 × 3 检查点 = 48 个配对，144 次候选训练。基准有 5 点/9 边/24 参数；任一展开后为 9 点/15 边/44 参数。每候选 1,024 次训练样本访问；继续、展开分别为 14,336、26,624 次训练输出端口访问（每例前向和反向各一次）。信号额外做 128 例全训练集梯度，即 1,792 次端口访问/配对；这是研究同时构造三个分支的额外成本，并非随机或继续策略单独运行所需。这个代理不含端口入度导致的算术差异、参数更新、建图及评估成本。预算相同指等 SGD 更新和样本顺序，不指等 FLOPs 或耗时。

混杂因素包括两种方向出现频率、拓扑位置与方向相关、展开后的参数化/梯度路径变化和候选初始函数保持路由。同一点的结果是配对相同而非独立数据。跨检查点反复使用验证集且共享训练轨迹，不能把 48 对当成独立种子；每格只有 8 对，未作显著性或等效性检验。不回答长期递归、等时间优势或同规模非五点 DAG 是否同样有效。若需分离方向偏好与选点质量，应增大种子数，并加入方向匹配随机对照、多个随机候选及等计算量对照。

## 实际观测

Windows 沙盒缺少共享 .NET 9 运行时，因此实验用包含 .NET 9 运行时的 `win-x64` 自包含 Release 构建运行，未改目标框架。下表为实测；各误差差值是格内配对均值，正数表示后述策略降低 MSE。最大初始验证预测差为 0。

|任务|检查点|保留 继续/随机/信号|同点|正向 随机/信号|验证 随机−信号|测试 随机−信号|测试 继续−所保留|
|---|---:|---:|---:|---:|---:|---:|---:|
|affine|0|5/2/1|1|5/8|-0.0000570321|-0.000264556|0.00822748|
|affine|64|4/2/2|4|7/7|0.00104388|0.000880316|0.00804594|
|affine|256|5/1/2|2|3/8|0.000692685|0.000643655|0.0004351|
|mixed|0|5/2/1|1|5/8|0.00204691|0.00172225|0.0581333|
|mixed|64|6/1/1|5|7/7|0.0158959|0.0127446|0.0342456|
|mixed|256|6/0/2|1|3/8|0.0135546|0.0116964|0.0357638|

- **何时展开**：按上述门槛，31/48 个检查点保留不改图。`affine` 首次接受在 0/64/256 更新处分别为 3/1/0 个种子，4 个从未接受；`mixed` 为 3/1/2 个，2 个从未接受。仿射任务也会接受展开，说明门槛衡量的是固定短预算下的收益，不是函数必然需要更大拓扑。
- **随机是否足够**：随机展开在六格都比继续训练降低平均测试 MSE，但 `mixed` 的三个检查点信号候选都进一步改善均值，尤其在 64 和 256 更新处。同时信号 46/48 次选到正向叶、随机 30/48 次，不能把差异归因于方向以外的选点质量，也不能据此声称随机与信号等效或信号普遍占优。
- **用什么分数保留**：这个独立验证分在六格内选出的策略，都比直接继续训练降低了平均测试 MSE。这是当前任务和预算下的观测，不是阈值最优性的证明。
