# FractalForge 最终集成验收记录

## 结论与范围

当前为可执行、可恢复的四点研究基线，已接入方向流式读取和真实语料有界烟测，**不是完整研究验收，不表示任一研究假设成立**。本轮核实代码与 `.coding-agent/fractalforge-real` 产物，实际更新 README、本记录和公共实现交接；未修改训练实现、包、TFM 或 Docs 历史，未使用 shell/脚本，未启动长程训练。

此前 Widening TextBindings 可空校验、Deepening D0/D1 非零扰动拒绝和冷却预算边界测试仍保留。本轮结果来自重新调用构建/测试并读取完整日志，不沿用历史数字。

## 数据、流式和恢复复核

- 公共 ForgeRunner 及 W0、Deepening、Adaptive 专用 runner 现均使用公开 `ForgeJsonlStream.ReadAsync`，不再整集加载 TokenDataset。读取样本前在同一文件流上核对整文件 SHA256，再顺序逐行读取，复用 PretrainingJsonl 的 tokenizer、截断和 EOS 语义；接受评价使用异步流及有效目标 token 加权。
- 数据限制覆盖文件/行字节、样本数、单样本及累计 token；恢复按完整样本位置重读跳过，跳过部分仍纳入预算。恢复不是随机寻址，也不是样本内恢复；长前缀恢复需要顺序扫描。短窗口结束不表示尾部 JSONL 语义已全部解析，完整哈希也不是全量训练证据。
- `ForgeCorpusPreparation` 语义为 `fractalforge.text-sha256.utf8.exact.mod4.v1`：对 JSON 解码后的精确 text 取 UTF-8 SHA256 的**首字节 % 4**，0=训练、1=提案、2=接受、3=最终测试。不是整个摘要整数取模；不做空白/Unicode 归一化。精确同文本不会跨角色，但角色内重复不删除，近重复/语义重复与全量质量仍需审计。
- ForgeCorpus 的可选 ContentRole 在已消费样本上验证；用途声明要求训练/接受/最终测试为 0/2/3。旧无角色配置兼容，只提供文件级隔离，不能声称已审计样本泄漏。三者身份、规范路径和文件哈希仍须不同。最终测试仅声明，训练/接受入口不打开它；预处理阶段会创建最终测试角色文件，不等于运行最终测试。
- 恢复包括参数、优化器矩、完整样本游标及方向策略/待决窗口；保持/候选同源、共同消费相同样本，配对两侧完整成功后提交。拒绝选已训练保持分支，不回退旧源。结构切换使用新会话，每个样本重置历史；跨结构历史迁移未交付。
- 文件输入要求不可变；本地只读共享句柄/哈希检查不等于跨平台防非协作写入、符号链接别名防护或签名。清单显式指定、不搜索最新文件；本地原子替换不承诺网络文件系统或掉电目录级持久性。

## 剩余任务与正式验收阻塞

1. **全量运行与数据约束**：流式迁移已完成，但全量语料训练、跨平台不可变数据约束、近重复/全量划分审计、恢复扫描成本及训练计算/内存测量仍未完成。
2. **跨结构状态迁移**：完整 F1 不变节点历史保留、F2 等价映射/证明、F3 训练/runner 持久化协调尚缺；需节点/时钟/延迟/历史身份校验，不能直接复用旧 RecurrentState。
3. **连续调度**：Deepening Next 为 API 而非跨轮 CLI 总事务；需要跨轮主线/候选总 token 与计算预算、断点发布及审计分段。Adaptive 多窗口不等于无限时长或完整研究总预算。
4. **方向语义**：W3 扰动分化、纯串行非线性加深、递归 O 定位/公共单元元数据、局部梯度/路径观测仍未完成。D2/D3 是保留父路径的逐来源 Tanh 四点旁路修正，不是纯串行替换；D3 仅有初始化目标预激活局部界，无训练期/全网损失保证，修正单元未登记 Core Units。
5. **研究报告**：没有正式长程多种子对照、统计选择控制、长依赖/扰动恢复曲线或隔离最终测试发布闭环。Adaptive 重复使用接受集存在选择偏差，未纠偏；接受成绩也不能替代最终测试结论。

这些是保留的后续工程/研究任务，不是本轮构建或测试失败；真实语料存在和有界烟测通过均不等于全量研究完成。
