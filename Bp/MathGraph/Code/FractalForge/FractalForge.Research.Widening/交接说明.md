## 准备与运行

入口参数（不含可执行文件名）：

- prepare request.json preparedDirectory
- train preparedDirectory/W1.json [本次更新上限]
- resume preparedDirectory/W1.json outputRoot/Widening/runId-W1/run.json [本次更新上限]
- inspect/evaluate preparedDirectory/W1.json 对应run.json
- generate preparedDirectory/W1.json 对应run.json prompt maxNewTokens seed
- diagnose preparedDirectory/W1.json tokens.json probes.json

W2 同理。W0 使用 W0.json，清单名为 keep.json，不是 run.json。先 train/resume 达到固定 MaxUpdates，再 evaluate，之后才能 generate。退出码：0 成功（也可能仅暂停）、1 配置/数据/运行失败、2 参数错误、130 取消。

request.json 是 WideningPreparation 的严格 PascalCase JSON：

- Run：完整 ForgeRunConfiguration，字段与公共 ForgeRunnerTests.CreateAsync 相同。明确提供真实 TokenizerPath、TokenizerConfigPath、Training/Acceptance/FinalTest（Path、Identity、Sha256）、DataLimits、RunId、OutputRoot、RuleVersion、MaxUpdates、MaxTokens、MaxPairTapeCells、MinimumGain、Optimizer、RandomState。三个划分身份、文件规范路径与大写 SHA256 必须不同。最终测试只声明，不读取。Sha256 是原始语料文件字节的 SHA256，不是文件名。
- SourceArchive：null 表示创建合法四点基线；否则显式现有 ForgeArchive 路径（可带训练状态）。不搜索最新文件。
- Seed：显式图初始化/新读出种子。
- Feedback：仅新建基线时控制 O→I 反馈；已有源保留其真实反馈。
- Target：真实计算节点身份，例如基线 A。
- UnequalAlpha：显式 W2 比例，例如 .3，不宣称最优。

Run 的 Semantics、Direction、SourceArchive、SourceSha256、TokenizerIdentity、Action 仍需作为完整公共配置字段提供；准备时会替换为实际公共版本、Widening、生成的源路径/指纹、真实词表身份、clone-widen/Target/alpha。因此不需要用户手工构造内部二进制模型，也不需要先知道生成源的指纹。其他 required 字段不得省略。

绑定规则 v1：无绑定源使用 I 输入、O 读出，编码 scalar(token)=tokenId/VocabularySize，internalSteps=1，固定读出 seed=Seed。已有绑定不重置，须与真实 tokenizer 身份/词表大小一致。此编码是明确控制变量，不是推荐最佳编码。

准备产物：内容 SHA256 命名 .forge 和 W0.json、W1.json、W2.json，各自 RunId 后缀隔离。使用新输出目录；准备不覆盖已有文件，失败可能留下未引用文件，不会清理目录。生成配置将路径固定为绝对路径。准备本身不训练、不读取语料或最终测试；实际 train 再执行语料身份检查。

W1/W2 生成内容命名 .run.json，由共享 runner 完成语料验证、同源配对、固定终点评价、接受、恢复。W0 独立 keep.v1 清单采用不可变模型文件先落盘 Flush，再原子替换清单；单写者锁；每次完整更新提交。W0 使用公共 PretrainingJsonl 有界整集加载，不是公共 runner 的逐行流式路径，内存开销受 DataLimits 限制，超大语料应暂用更小预登记窗口。W0 顺序读取，不洗牌，RandomState 固定但不消耗。

## 指标口径

- MeasureLoss：同一合法 token 序列、零初始历史、公共 EvaluateTokens。Delta=候选交叉熵−源交叉熵，未训练之前测量。
- MeasureBranches：显式内部步输入探针，公共 GraphInterpreter.Run；记录 A/B 激活 Pearson 相关性；常量或单点序列返回 null，不伪造 0。
- A/BWeightedRms = sqrt(mean(分支激活²) × sum(各出边当前权重²))。这是局部加权信号幅度，不是因果消融贡献、词表损失贡献或梯度贡献。
- diagnose 从实验源构造实际候选，输出损失、信号和两个探针内容身份（规范序列化 SHA256）。tokens.json 为 token ID 数组；probes.json 为每内部步节点输入字典数组，例如 [{"I":0.2},{"I":0.8}]。token 探针与显式输入探针分别测量，不能谎称二者自动对齐。
- API 可对训练后模型测量分支信号；当前 CLI diagnose 只测源/动作即时状态，不自动加载训练后分支或汇总适应曲线。
