## 准备配置与基线

可执行入口参数：`prepare templatePath configPath seed Local|CrossLayer delay weight F1`。

模板是完整 ForgeRunConfiguration 严格 JSON，字段以 Training.Tests/ForgeRunnerTests.cs 为真实示例。必须预登记独立 RunId、OutputRoot、三份数据声明、规则、优化器、预算及 RandomState；prepare 不编造语料、预算或最优值。保留模板这些字段，设置 Feedback 方向、当前语义、源档案和指纹、真实 tokenizer 身份及动作。输出 configPath 和 configPath.forge；拒绝覆盖。路径按进程工作目录解析，建议绝对路径；父目录须存在。档案先落盘、配置最后落盘，取消/写入错误可能留下孤立档案，不能将其当已发布配置，也不自动清理其他文件。

基线 I/A/B/O 为四个计算点，默认保留 O→I delay=1。固定编码为 tokenId/vocabularySize 的单标量 I 输入，O 读出，内部步 K=1；Tanh 与参数初始化来自公共 CreateDiamond。seed 同时明确控制初始化和读出，不是最优推荐值。可通过 CreateBaseline 显式传入其他合法绑定，或使用现有已绑定源档案，而不执行 prepare。

Local：只加 A→A 正延迟自反馈。CrossLayer：只加 O→I 正延迟跨层反馈，可以与原 delay=1 路径并存；不同延迟是独立物理连接和参数，不合并。Weight=0 仍消耗连接/历史预算。动作不执行扩宽/加深，保持所有旧节点、前向路径、参数/矩/更新次数和读出，新增参数零矩。实际合法性与资源预算由 ForgeModel.Apply 再校验。通用配置也允许显式选择其他计算源/目标，但必须是 add-feedback。

保持分支本身就是“保留原反馈”对照；候选只增加一条局部或跨层边。不同方案应复用同一只读基线档案、数据、优化器、种子与更新预算，使用不同 RunId。训练窗口内保持/候选按相同完整样本和顺序各自独立更新。无反馈可通过 CreateBaseline(feedback:false) 做单独声明的消融，不冒充循环基线。

## 状态语义与限制

- **F1ZeroReset**：真实可运行的全零历史受限路径。每个训练/评价样本重置；每次 generate 新建会话，以提示从零消费。结构改变绝不复用旧 RecurrentState。不是任务书完整 F1 的“不变节点保留历史、新节点零历史”；该跨结构映射目前未实现。
- **F2EquivalentRestore**：只在 ForgeArchive 完全相同的保守充分条件下调用共享 RestoreGenerationSession，后者再次验证真实计算/文本指纹、历史长度、上下文和时钟。恢复持续历史、待采样 logits、上下文和采样随机流。任何结构变化（包括零权重新边）明确抛 NotSupportedException，不猜测节点同名等价。数值变化也拒绝；不声称覆盖全部语义等价变换。
- **F3SeenPrefix**：WarmSeenPrefix(keep,candidate,seenTokens,predictionPosition,...) 只把索引 [0,predictionPosition) 复制给两个全新执行器。索引 predictionPosition 及之后不读取、不编码；调用方必须保证传入前缀确为共同已见内容。严格核对 tokenizer、词表、内部步及真实编码/输入/读出定义。使用共享检查点的 Text 字段做保守比较，无反射、无开放 setter；共享检查点字段变化需重新验证。本 API 不迁移旧缓存或旧随机流，明确从同一种子建立新生成会话。重放成本报告两侧合计 prefixLength*K 内部步；不是完整 FLOPs 或历史映射。

训练入口只有 F1；ValidateConfiguration 对 F2/F3 训练请求明确拒绝。F3 是可执行且经测试的生成实验 API，尚未扩展公共 runner 命令/清单。生成同会话内历史持续，跨命令 generate 不自动恢复。F2 API 可显式恢复同结构会话，与训练 resume 的优化器/样本游标恢复分开。

公共训练对完整样本做既有 BPTT，不跨样本传状态；即便显式连续运行执行窗口，窗口外梯度也被截断。不能把 F2/F3 的生成收益归因到样本重置训练。

## 使用共享运行命令

- `train configPath [invocationUpdates]`
- `resume configPath manifestPath [invocationUpdates]`
- `inspect configPath manifestPath`
- `evaluate configPath manifestPath`
- `generate configPath manifestPath prompt maxNewTokens seed`

resume 只认显式清单，配置变化不允许恢复；继承共享同源事务、单写者锁、内容哈希、完整样本游标、预算、方向/run 隔离。最终测试只声明且不读取。配置与运行语义由共享 runner 完整校验。每次调用输出独立训练/生成协议报告以及共享结果；成本和配对损失来自共享真实模型，不另造训练器。

## 验证与未完成项
