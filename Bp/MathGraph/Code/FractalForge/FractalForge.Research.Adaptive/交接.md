## 策略准确语义

机会条件为 `updates >= WarmupUpdates && updates % OpportunityInterval == 0`；待决窗口期间不产生新提案；一个机会只抽样一次。冷却从启动窗口的主线更新编号计算，MaxTrials 按已选定动作/启动尝试计，拒绝也消耗预算。

- A0：增长概率恒零，正常训练，不预构造候选。
- A1：固定机会的 GrowthProbability，类别均匀，所选类别内具体动作/位置均匀，不是对全部候选一次均匀抽样。
- A2：至少两次训练损失观测后，增长概率乘平台系数 `clamp(1-max(0,近期相对改善)/PlateauScale,0,1)`。类别与位置用平台/退化启发式正分数；没有梯度/激活位置统计，不能解释成局部梯度策略。
- A3：增长意愿保持固定概率，类别/位置按线性评分 softmax 权重和显式 epsilon 均匀混合。8 维上下文是截距、平台、归一化改善、三类动作 one-hot、目标/目的位置稳定 FNV 编码。位置编码只是轻量身份特征，不代表空间距离。类别权重为该类别位置分数平均值，候选数不自动提高类别权重。

提案保存 growth probability/draw/wants、类别概率、位置概率和联合概率。增长抽样独立于候选数量；过滤后空集仍记录增长意愿与 no-candidates，绝不把它变成拒绝收益标签。

只有实际尝试且达到终点的 `KeepLoss-CandidateLoss` 学习（包括真实负收益的 rejected）；收益裁剪到 [-1,1]，归一化残差 SGD。accepted/rejected 由公共固定阈值规则决定；无置信区间，不把零收益自动叫作统计不确定。uncertain 专指未完成窗口显式放弃，fault 专指故障；两者无收益、不更新权重。未采样动作和适用性过滤不学习。每次接受评价计数，重复使用接受集存在选择偏差，未做统计纠偏。

候选预验证实际调用 Model.Apply，可能有构造成本，但不训练未抽中的候选、不使用其收益。固定动作集合在配置中预登记，不引用其他方向入口。

## 可用入口与配置路径

以下均为可执行程序的参数说明，不是本轮已启动的训练任务。所有相对路径按进程当前目录解析，正式配置建议绝对路径。

1. 准备公共模板：参照 `../FractalForge.Training.Tests/ForgeRunnerTests.cs` 的 CreateAsync，提供全部 ForgeRunConfiguration required 字段（独立 RunId/OutputRoot、三份不同 Path/Identity/Sha256 的语料声明、真实 tokenizer 路径、DataLimits、窗口与接受阈值、Optimizer、RandomState）。哈希是大写 SHA256；训练/接受语料为真实 `{text:string}` JSONL。SourceArchive/SourceSha256/TokenizerIdentity 可先填占位值，prepare 会真实生成并替换。Base.Action 仅公共结构兼容，Adaptive 实际用外层 Actions。
2. 策略文件：使用本目录 `adaptive-policy.example.json`，按研究预登记修改；比较 A0/A1/A2/A3 时各复制独立 RunId，固定源 seed/反馈、数据、动作集合、接受规则与预算，仅改变 Branch 及事先指定的策略变量。
3. 参数 `prepare 公共模板.json 策略.json 输出adaptive.json seed feedback`：创建真实四点基线、固定标量 token 编码 `id/vocabularySize`、I 输入/O 读出及词表参数。feedback 显式 true/false，不冒充已实现其他反馈状态迁移。输出 `输出adaptive.json.source.forge` 和完整 AdaptiveConfiguration。prepare 默认候选是 A/B clone-widen(.3)、A/B output-deepen、O→A add-feedback(delay=1,weight=.01)。可在首次 train 前编辑生成配置登记候选，恢复后不允许变更。
4. `train adaptive.json 本次主线更新数`：从源启动，目录 OutputRoot/Adaptive/RunId，保存 adaptive.json 清单。更新数必填，不会默认长程训练。
5. `resume adaptive.json 明确清单 本次主线更新数`：从明确清单继续，不重抽 pending 动作。若上次在固定终点暂停，先完成接受评价再消费新训练样本。每次普通/双分支共同更新后保存。
6. `evaluate adaptive.json 清单`：仅评价到达终点的 pending；A0 没有候选窗口，故不支持此命令。`inspect adaptive.json 清单` 输出进度、策略、过滤、成本；`generate adaptive.json 清单 提示词 新token数 seed` 对无 pending 的已发布模型真实生成，A0 同样可用。

可运行完整配置生成示例也在 `../FractalForge.Research.Adaptive.Tests/AdaptiveRunnerTests.cs`，包括 prepare、短训练/恢复/评价/生成；最终测试路径故意不存在，证明入口不读最终测试。

## 保存与恢复

先 Flush 内容哈希模型和公共 trial 分支/清单，再最后原子替换方向清单。保留随机流、EWMA、权重、提案/结果、冷却/预算、游标、主线/额外候选 token、接受评价次数与过滤记录。恢复检查内容哈希、语义、配置契约及 pending 动作/游标，不按时间找最新文件。

入口把完整 AdaptiveConfiguration 哈希纳入 TrialProtocol.RunId，所以路径、语料、源档案、最终测试声明、优化器及策略改变均拒绝恢复。Session API 单独使用时契约固定 options/protocol/actions；调用方负责额外的数据内容身份和独占锁。普通更新也在副本上训练，失败不发布半更新模型。

保存可能留下孤儿临时/内容文件，不自动清理其他运行。清单与策略审计有界读取上限 16MiB；无限增长审计需要后续分段，不宣称无限时长恢复。

## 公共 runner 限制与未完成

公共 ForgeRunner 只支持一个固定动作、一个从源开始的窗口，内部 Protocol/语料流/清单均不可直接复用为多窗口回调；也没有无增长 train 模式。未修改公共层。本方向通过公开 PairedTrial/Neural API 提供真实多窗口调度，未复制训练器；公共 runner 仍可用于手工单窗，但不能自动携带 Adaptive 策略状态。

方向入口复用公开 PretrainingJsonl，按 DataLimits 整体加载有界 TokenDataset，并非公共 runner 的逐行流式方案；超过数据边界明确失败，不静默循环。长期大语料流式调度仍需公共层开放受校验的数据流/普通更新及 checkpoint 钩子，或方向内进一步有界流式实现。

动作目标固定：clone 后旧 A/B 可能退役，后续明确过滤，不自动把新 Guid 节点加入集合。尚未实现动态新位置枚举、局部梯度统计、位置嵌入、序贯接受、置信区间、全研究总计算精确计量或多种子质量报告。PairTokens 只计算候选额外训练 token，不含预验证、损失观测和接受评价计算，不能当作精确总 FLOPs。故障时入口保留最近完整清单并返回错误；Session.Abandon 可显式以 fault/uncertain 发布已对齐保持，入口尚无 abandon 命令。

不支持跨结构历史迁移、最终测试报告入口或生成会话断点存储（生成 API 本身沿用现有执行器）。A0 的独立留出指标报告仍需后续添加；目前 A0 支持真实普通训练/保存恢复/生成而非配对评价。

未开展长程训练、收益优劣和多种子结论；没有把开发验证解释成研究假设已成立。
