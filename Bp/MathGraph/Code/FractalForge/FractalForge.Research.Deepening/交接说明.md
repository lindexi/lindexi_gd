# Deepening 实现交接（v1）

## 修改范围与依赖

仅修改 FractalForge.Research.Deepening 和对应 .Tests；未修改共享 Training/Core/Neural、其他方向及 Docs。net9.0，无新增包。已阅读 Docs 24/25、公共实现交接及实际 API。

依赖 ForgeTopology explicit-routes.v1、ForgeArchive、output-deepen、Neural RootModelBridge、真实 TrainTokens/EvaluateTokens/CreateTextSession。用户授权覆盖文档中的历史开发禁令。

## 实际算法

- D0：完整归档克隆，保持结构继续训练，两侧仍同序消费。
- D1：公共 output-deepen，逐条来源独立建立 Identity A/B，保留源权重、出口各 0.5。拒绝不适用的共享参数、自环、延迟入边；不是 Tanh(weight=1)，不宣称增加非线性表达能力。
- D2：保留全部父路径及其参数身份/值/AdamW 矩；每条来源独立增加两个 Tanh 修正路径，输入权重为当前源权重的 1 与 0.5 倍，出口门为零。初始函数保持，门经真实反向可启动；内部路径第一步因零门梯度受阻是方案性质，不隐藏。
- D3：同样保留父路径，新增 Tanh 修正出口门为 epsilon/(2*来源数)。由于 |tanh|<=1，初始化目标预激活附加项绝对值 <= epsilon；目标为 Tanh/Identity/ReLU 时局部输出同界。不是全网损失界、训练期门约束或原路径被完全替换的纯串行非线性加深。
- 多来源不在透明 O 聚合；每条来源拥有独立新参数。D2/D3 拒绝目标自环和延迟入边，非目标已有反馈原样保留。所有新参数矩归零；未变参数与文本读出保留完整状态。
- Core v1 Units.Kind 仅允许 clone-widen/output-deepen，不能登记 D2/D3 为虚构公共动作。故其边界和逐来源路径保存在真实拓扑，修正门 ID 与目标保存在方向实验状态；未滥用公共动作名。

## 入口与配置路径

程序入口接 Ctrl+C，取消返回 130；错误资源位于 Messages.resx。CLI 错误返回 1，成功/暂停返回 0。

版本化模板：`Experiments/v1/D2.template.json`。模板所有 REPLACE 字段必须替换为真实绝对路径和内容身份；这是两次更新的短测试规模，不是推荐超参数或已完成研究实验。Branch 数值 D0=0、D1=1、D2=2、D3=3，Run.Action.Kind 必须相应显式写 D0/D1/D2/D3，Target 为实际内部计算节点；D3 的 Weight 为正 epsilon，其他分支为零。

命令参数（不是 shell 脚本）：

- `prepare tokenizer.json tokenizer_config.json source.forge seed`：真实 MiniMind tokenizer、四点基线、原有 O→I delay=1 反馈、固定标量编码 i/vocab，输出来源 SHA256 与 tokenizer identity；不覆盖已有源文件。编码仅为可复现基准，不声称最优。
- `train config.json checkpoint.json [本次更新上限]`
- `resume config.json checkpoint.json [本次更新上限]`
- `inspect config.json checkpoint.json`
- `evaluate config.json checkpoint.json`
- `generate config.json checkpoint.json 提示词 新token数 seed`（确定性 greedy；seed 保留为显式协议参数）
- `cooldown config.json checkpoint.json [本次更新上限]`

检查点必须位于 OutputRoot/Deepening/RunId 直接目录；每运行 writer.lock。源模型和 tokenizer 每命令核对，配置未知/重复属性拒绝。配置序列化身份绑定规则、划分、源路径和动作，resume 不静默改配置。最终测试文件从不打开。训练和接受文件在使用时同一流校验哈希后读取。

公共 ForgeRunner 只有公共动作构造入口，不能注入 D0/D2/D3 候选；因此实现方向专用 DeepeningRunner/DeepeningExperiment，未修改或复制公共优化器。保留 Run 字段结构方便对照公共测试，但 Deepening Action 由方向策略解释，不能把本模板直接交给公共 ForgeRunner。

## 配对、恢复、连续生长与指标

同源双分支、相同样本顺序、零历史独立 TrainTokens；两侧成功后才同时提交模型及完整样本位置。窗口终点 token 加权接受，gain 严格大于 MinimumGain 才选候选，否则选已训练保持分支，绝不回滚旧源。诊断消融最新修正门并记录 AblatedLoss；该差值只是功能贡献诊断，不是梯度、路径输出幅度或因果结论。D1 无修正门时消融为空，不伪报贡献。

单文件检查点包含双方完整 ForgeArchive、源指纹、目标、门身份、游标、有效目标 token、更新、冷却、评价及决策；临时文件 Flush(true) 后原子替换。恢复显式指定文件且匹配规则，不搜索最新文件。

DeepeningExperiment.Next 在接受与冷却完成后以完整选中模型及消费位置开始下一轮；目标可为稳定计算 ID，或 D1 Units 中局部透明 O（显式解析到记录的 Target），不是透明节点计算。可再次展开原汇合点或选择新增 A/B。冷却继续训练选中模型并计入 token 上限；尚未提供 CLI 自动多轮调度/跨轮事务总清单，调用方须显式调用 Next 与保存新轮。最长计算路径统计忽略正延迟边，旁路父边实际保留。

## 已验证与不足

MSTest 包含真实数值 D0/D1/D2、非零门反向启动、D3 界与数值扰动、多来源分离、父路径保留、延迟拒绝、局部 O 定位、恢复数值一致、规则变更拒绝、固定终点评价、冷却与 Next、取消；真实 tokenizer 集成测试走 prepare→train→resume→inspect→evaluate→generate→cooldown，最终测试路径故意不存在。

不宣称完成研究收益：未做长程训练、多种子统计或正结果报告。

明确限制/阻塞项：

1. 非目标原反馈支持，目标延迟入边/自环加深未实现；跨结构循环历史迁移依赖公共能力，使用样本重置和新生成会话。
2. 没有纯局部 O→O 新计算语法；O 只是已记录合流目标定位。D2/D3 的单元元数据受 Core Kind 白名单限制，但实际路径、门和目标完整保存。
3. 无公共逐路径激活/梯度观测 API；未提供梯度范数、恢复所需训练量自动判定、所有旧修正路径逐项贡献曲线。
4. 数据使用有界 PretrainingJsonl/TokenDataset 整集加载，而非公共内部流式适配器（internal 不可访问）；正式大语料需严格控制 MaxTotalTokens。无自动洗牌，RandomState 不消耗；初始化不消耗语料随机流。
5. CLI 为单轮加冷却；连续生长协调是可测试 API，而非完整持久化多轮自动研究调度器。
6. 单文件检查点没有额外密码学防篡改签名，模型由 ForgeArchive 验证；仍需调用方使用可信本地检查点。未实现进程内存实测与全研究总计算预算。
