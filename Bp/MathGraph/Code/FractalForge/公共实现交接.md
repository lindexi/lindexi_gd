# FractalForge 公共实现交接

## 当前实施范围与兼容边界

本页反映当前 Core/Training 和四方向接入状态；Docs 保留历史原貌。目标框架 net9.0，沿用现有包和语言配置。独立解决方案为 `MathGraph/FractalForge.slnx`。本轮仅更新三份状态文档，未修改训练实现或启动长程训练；准确验证见 [集成验收记录](集成验收记录.md)。

基线 I/A/B/O 为四个计算点，无 M，不包装 FiveNodeGraph。展开单元 I/O 是透明边界，A/B 是计算点。ForgeRoute 保留每条信号路径、独立参数、延迟和平行边，编译为普通 Neural 根图，复用现有前向、BPTT、AdamW 和文本生成；没有第二套训练器。旧 RecursiveNetwork.Fractalize、Neuron.Child、五点出口和旧检查点格式保持兼容。

语义版本：`ForgeTopology.Semantics=fractalforge.explicit-routes.v1`、`PairedTrial.Semantics=fractalforge.paired-trial.v1`、`ForgeRunner.Semantics=fractalforge.console-run.v1`。未知语义/额外配置字段拒绝。

## 公共模型与结构 API

- `ForgeTopology.CreateDiamond(seed, feedback)` 创建四计算点；可选 O→I 正延迟反馈。seed 控制数值，不控制 Guid。
- 显式拓扑包含 nodes、biases、routes、units。route 从计算源开始到计算目标结束，中间只可为透明边界；一个 route 对应一个标量权重和延迟，不隐式合并多个串联可训练参数。Expand 逐来源保留独立物理连接，透明 O 不求和、不激活。
- `ForgeModel.Create(topology, budget)` 通过 Neural 布局验证节点、边、环、延迟及历史预算。调用方先 BindText，绑定固定 tokenizer 身份、词表和输入/读出节点，然后使用 TrainTokens/EvaluateTokens；每完整样本重置历史。
- `ForgeArchive.Export/Import` 保存逻辑路径、真实数值、优化器矩和更新计数，Fingerprint 为 SHA256。逻辑初始化值不是当前训练值，恢复以 Neural 检查点为准。
- `model.Apply(action, ct)` 返回独立候选，失败/取消不发布源变更；MeasureCost 返回逻辑/执行节点、物理边、参数、历史/tape 标量估算，不是精确托管堆字节。
- Neural RootModelBridge 仅用于建立稳定参数/连接身份、复制未变参数和读出状态、重建根图；不放宽 setter，不接入旧 Pending/PipelineTraining 控制事务。旧递归子图或已配置 controller/trainingJob/pipeline 的模型不能借此绕过原约束。

### 公共动作边界

- `clone-widen`：独立 A/B 克隆、入权重/偏置复制、出权重按 alpha/1-alpha 拆分。未变参数身份/值/矩保留，新参数零矩。当前只证明适用前馈条件下零初始历史函数保持；拒绝目标自环、相邻延迟、相关共享参数及直接文本输入/读出目标。
- `output-deepen`：每个入边来源独立建立 Identity A/B 四点路径，出口各 .5，保留原目标计算及偏置；透明 O 不聚合。新参数零矩，重参数化入参不延续矩。拒绝共享入参、自环及延迟入边，不声称非线性容量增加。
- `add-feedback`：新增计算点之间正延迟物理边，新参数零矩，复用普通执行器/BPTT。

所有动作重建布局，新结构不接收旧 RecurrentState。Deepening 方向另有 D2/D3 Tanh 四点旁路修正，保留父路径而非纯串行替换；门/目标由方向状态保存，未登记 Core Units。W3、完整递归 O 定位/元数据与纯串行非线性语法仍未完成。

## 配对事务与持久恢复

固定 TrialProtocol 包含 run/data/evaluation/rule 身份、更新/token/tape 预算、MinimumGain 和优化器。Begin 从同一源快照派生保持/候选，保存源哈希；Advance 两侧消费相同完整样本，仅都训练成功且未取消才共同提交模型、Position、Tokens、Updates 和外部随机状态。

Evaluate 与 `EvaluateAsync(identity, IAsyncEnumerable<IReadOnlyList<int>>, ct)` 均只允许固定更新终点，以有效目标 token 加权；错误、空流、取消不发布评价。Complete 仅在收益严格大于 MinimumGain 时选候选，否则选已训练保持分支，不回退旧源。不提供统计显著性或重复选择纠偏。

Save 先持久化内容寻址分支和 trial，再替换显式清单；Load 核对协议、语义、路径、哈希与进度，不按时间搜索“最新”。失败可能留孤儿文件，不自动清理。方向/run 使用独立目录和单写者锁；本地替换不承诺网络文件系统/掉电目录级持久性，也不是签名防篡改。

恢复包括模型参数/矩、完整样本游标和方向策略/待决窗口。结构切换使用新会话、样本零历史。Feedback F2 仅在同模型保守条件下恢复生成历史/采样状态，跨结构拒绝；F3 共同已见前缀重放 API 尚无训练/runner 持久化协调，不读取未来，也不是完整跨结构映射。

## 流式数据与稳定内容角色

`ForgeJsonlStream` 现为公开公共组件：

- `VerifyAsync(corpus, maxBytes, ct)` 校验文件预算和完整字节 SHA256。
- `ReadAsync(corpus, tokenizer, limits, skip, ct)` 在发布第一个样本前于同一流核对整文件哈希，再逐原始 UTF-8 行调用现有 PretrainingJsonl，复用截断/EOS 语义，不缓存整集 TokenDataset。
- 公共 ForgeRunner、Widening W0、Deepening 和 Adaptive 专用 runner 已接入；接受评价也使用异步流。恢复按完整样本位置顺序重读前缀，跳过部分仍计入样本/累计 token 预算；不支持样本内游标或随机定位。
- DataLimits 限制文件/行字节、样本数、单样本/累计 token。窗口结束不解析未消费尾部所有 JSONL；整文件哈希核对不等于全量语义审计或全量训练。

`ForgeCorpus` 当前为 `(Path, Identity, Sha256, ContentRole = null)`。`ForgeCorpusPreparation.PreparePrefixAsync` 有界读取源前缀，输出 training/proposal/acceptance/final-test.jsonl 及 provenance.json。语义 `fractalforge.text-sha256.utf8.exact.mod4.v1`：

1. JSON 解码后的精确 text 编码为 UTF-8，取 SHA256 **首字节 % 4**（并非整个摘要整数取模）。
2. 固定 0=训练、1=提案、2=接受、3=最终测试，不做空白/Unicode 归一化；相同精确文本总在同角色，角色内重复不删除，近重复/语义重复不保证隔离。
3. 配置声明角色时训练/接受/最终测试用途必须为 0/2/3；ReadAsync 对已消费样本校验角色。旧无角色配置仍只保证文件级隔离，不能宣称样本无泄漏。
4. SourceRecords、SourceBytes、PrefixSha256、ReachedEnd 记录实际消费范围。前缀哈希不是全量源哈希，各角色输出文件另有内容哈希；ReachedEnd=false 时明确未读完整源。

训练/接受/最终测试仍必须身份、规范路径、SHA256 两两不同。最终测试仅声明，不由 runner 打开或用于接受；预处理写出最终测试角色文件不等于执行最终测试。提案角色已准备，但不代表方向已使用独立提案集。

文件要求不可变本地输入；只读共享句柄和哈希检查不承诺防非协作 Unix 写入/符号链接别名。跨平台不可变约束、近重复及全量审计尚待完成。

## 运行配置、命令和方向入口

`ForgeRunner.RunAsync(expectedDirection, arguments, output, error, cancellationToken)`：方向由入口硬编码，退出码 0 成功/显式暂停、1 运行/数据/清单错误、2 参数错误、130 取消。提示位于资源文件。配置严格拒绝未知/重复字段，明确源档案/哈希、tokenizer 路径与身份、三个数据划分、预算、动作、优化器和规则。相对路径按进程工作目录，而非配置文件目录解析；恢复绑定配置语义，不允许静默换数据或规则。

公共命令：

- `train configPath [invocationUpdates]`：新建配对窗口，按显式单次上限暂停；已有 run.json 拒绝覆盖。
- `resume configPath manifestPath [invocationUpdates]`：显式恢复最近完整发布状态，不重新抽动作。
- `inspect configPath manifestPath`：校验并显示进度/成本，不训练。
- `evaluate configPath manifestPath`：恰好窗口终点后流式接受评价并完成决定，只一次。
- `generate configPath manifestPath prompt maxNewTokens seed`：对已决定分支生成；当前公共 CLI 固定贪心，不提供生成会话持久化命令。Neural API 自身支持同模型生成状态恢复。

公共 run.json 绑定方向/run-id、配置/源哈希、trial 文件及哈希、完整样本进度与随机状态。游标语义为 `sequential-complete-samples.zero-history.random-unchanged.v1`。方向专用状态另含其策略和规则，不能跨入口混用清单。各 Program 已有真实入口和 Ctrl+C 令牌传递，不再是未接线 stub；W0/Deepening/Adaptive 使用各自专用 runner，Feedback 及适用公共配对路径复用 ForgeRunner。各方向命令/策略参见对应交接与当前代码；若旧方向交接仍称整集加载，以本页、当前代码及验收记录为准。

这是有界顺序训练与方向实验支撑，不是完整长期生产调度系统。没有 epoch/洗牌、样本内分块、聊天 mask、总峰值内存硬限制、自动最优值选择或最终测试发布命令。Deepening Next 仍是 API；Adaptive 多窗口/有界审计不等于跨轮无限时长总预算。
