## 2. 改造目标

将原可运行演示工程改造为可配置、可诊断、可测试、可发布的 Windows 桌面 AI 工作区，形成真实 Agent 调用、本地可靠持久化、产品化交互、隐私边界和发布支持闭环，同时保留清晰的人工验收边界。

## 3. 用户确认的六项决策

1. **产品定位**：产品名统一为 DeepSeek Workspace，目标用户为个人开发者。
2. **模型与提供者**：使用 AgentLib 已注册的全部提供者和模型，不在 WPF 项目中维护单一 DeepSeek 专用列表。
3. **凭据配置**：端点与 Key 由外部 `AgentConfiguration.json` 管理；可用 `DEEPSEEKWPF_AGENT_CONFIG` 覆盖默认路径；设置页只选择模型。
4. **Agent 能力**：首版直接提供真实多轮流式 reasoning/text 和 AgentLib 默认工作区工具；生产项目与发布产物禁止包含 Mock/Fake 实现。
5. **数据与隐私**：设置、会话、日志和诊断摘要不主动保存 Key 或聊天正文；诊断数据默认只保存在本机且不自动上传。
6. **发布与验收**：发布 Windows 10/11 x64 的 .NET 10 framework-dependent zip；自动化门禁与真实账号、性能、DPI、可访问性和 Windows 矩阵人工验收分开记录。

## 4. 按步骤关键改动

### 4.1 工程底座

- 引入 Generic Host，统一依赖注入、日志和生命周期。
- 将设置、日志、仓储、模型、聊天、诊断、交互、导出、ViewModel 和主窗口纳入容器管理。
- 建立启动初始化、全局异常处理和受控关闭流程。

### 4.2 外部 Agent 配置与真实模型

- 新增 `IAgentModelService`，通过 `AgentApiEndpointManager` 加载全部注册模型。
- 配置路径优先读取 `DEEPSEEKWPF_AGENT_CONFIG`，否则使用 `%LocalAppData%\DeepSeekWpf\AgentConfiguration.json`。
- 设置页移除 API 地址和 API Key 编辑，只保留模型选择、配置重载、打开配置和连接测试。
- 生产聊天实现切换为 `AgentAiChatService`，按所选模型获取 `IChatClient`。

### 4.3 真实流式 Agent 对话

- 将完整会话历史转换为标准聊天消息，支持真实多轮上下文。
- 分别映射 `TextReasoningContent` 和 `TextContent`，在界面增量展示 reasoning 与 text。
- 为当前数据目录创建 AgentLib 默认工作区工具。
- 支持用户停止、请求超时、可恢复错误自动重试和失败轮次显式重试。

### 4.4 会话与设置可靠性

- 设置与会话仓储改为异步 API。
- 设置采用临时文件加替换的原子保存，并验证缓存、数据和日志目录可写。
- 会话采用每会话一个 JSON 文件、同会话有序写入和过时操作丢弃。
- 会话最初引入 `SchemaVersion = 2` 并自动迁移 v1；图片输入上线后升级为 `SchemaVersion = 3`，继续兼容 v1/v2，单文件损坏不阻止其他会话加载。

### 4.5 产品交互

- 统一产品名和空状态、加载状态、错误状态。
- 增加会话搜索、重命名、删除确认和最近删除撤销。
- 历史消息编辑保存后截断后续上下文。
- 增加停止、重试、Markdown/代码显示、Markdown 导出和智能自动滚动。
- 支持 Enter/Ctrl+Enter 发送策略、Shift+Enter 换行及常用全局快捷键。

### 4.6 日志、诊断与隐私

- 建立 `IAppLogger` 与 `ILoggerProvider` 统一入口。
- 文件日志异步顺序写入，按日记录，保留 14 天并限制总量。
- 诊断摘要包含版本、运行时、操作系统、路径、模型和错误摘要，不包含 Key 与聊天正文。
- 设置页支持复制诊断摘要、打开日志目录和清理日志。
- 未实现、也不计划默认启用任何自动诊断上传。

### 4.7 测试、CI 与发布

- 增加独立测试项目，使用仅编译在测试项目中的替身验证核心逻辑。
- 覆盖设置迁移、会话 v1→v2、仓储读写、错误映射、停止/重试和 ViewModel 交互。
- CI 执行 Release 构建与测试。
- 增加 `win-x64` framework-dependent 发布配置和 `build/publish.ps1`。

## 5. 关键技术决策

- **Host 生命周期**：WPF `async void` 仅保留在框架入口，业务初始化和关闭均使用可等待任务。
- **服务生命周期**：当前单窗口状态服务和 ViewModel 使用 Singleton；模型客户端按请求创建并释放。
- **配置隔离**：凭据不进入 `AppSettings`，模型选择使用 `Provider/ModelName` 标识。
- **流式可靠性**：流式保存按 500 ms 节流；一旦开始输出，失败时不自动重放，避免重复内容。
- **错误模型**：按配置、认证、限流、网络、超时、服务端、协议、空响应、存储、取消和未知分类。
- **数据一致性**：设置和导出采用原子替换；会话在原子替换基础上增加同会话操作版本控制。
- **UI 体验**：滚动只在用户接近底部时跟随，并以 75 ms 节流。
- **隐私最小化**：日志记录关联标识和错误上下文，不默认记录消息正文、Key 或认证头。

## 6. 文件与数据迁移

### 6.1 设置迁移

- 默认设置文件仍为 `%LocalAppData%\DeepSeekWpf\settings.json`。
- 旧 `ModelName` 在读取时迁移到 `SelectedModelSpecifier`。
- 旧 API 地址与 API Key 字段不再属于设置模型，不再读取、使用或写回。
- 端点与 Key 应手工迁移到外部 Agent 配置文件。
- 旧 `agent-endpoints.json` 不再是默认文件名；迁移时应重命名为 `AgentConfiguration.json`，或通过 `DEEPSEEKWPF_AGENT_CONFIG` 继续指定原路径。

### 6.2 会话迁移

- 当前会话格式写入 `SchemaVersion = 2`。
- 缺少版本或版本为 1 的会话，在加载时将旧 `Content`/`ThoughtContent` 映射为 v2 `Text`/`Reasoning`。
- 原文件在读取失败时保留；用户应先备份，再修复或移出 `Sessions` 目录。

### 6.3 路径迁移

- 默认会话位置为 `%LocalAppData%\DeepSeekWpf\Data\Sessions`。
- 用户修改数据目录后，应用使用新目录，不自动复制旧目录内容。
- 切换前应备份旧目录，并按需手工复制会话 JSON。

## 10. 诊断上传声明

DeepSeek Workspace 不自动上传诊断摘要、日志、会话、Agent 配置或其他用户数据。复制诊断摘要、导出会话和分享日志均由用户主动执行；支持请求不得要求用户提供 Key 或聊天正文。

## 11. 真实对接加固记录

本轮继续补齐了真实服务对接的产品闭环：

- 连接测试改为调用流式接口，确保测试路径与正式对话依赖的能力一致。
- 配置重载后立即同步界面所选模型与实际请求模型，避免显示模型和调用模型不一致。
- 已保存模型在外部配置中失效时不再阻止应用启动，改为回退到配置主模型并记录警告。
- 正式对话和连接测试均兼容异步释放模型客户端，减少重复调用造成的连接与句柄泄漏风险。
- 增加图片选择、预览、移除、持久化和多轮发送，使用标准 `DataContent` 发送给真实模型服务。
- 图片选择支持 PNG、JPEG、WebP 和 GIF；不在客户端硬编码数量、体积或模型能力门禁，服务兼容性与请求限制按真实响应处理；附件复制到 SchemaVersion 3 会话 JSON。
- 隐私文案修正为“不在界面回显、应用设置或日志中保存密钥”，避免与底层读取外部凭据的真实行为冲突。

后续已撤销基于本机环境固定 SDK 补丁版本的错误改动；`global.json` 不再指定具体版本。图片功能与其后的修正仍需通过 Release 构建及真实账号端到端验收。
