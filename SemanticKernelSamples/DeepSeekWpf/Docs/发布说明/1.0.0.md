# DeepSeek Workspace 1.0.0 发布说明

发布日期：2026-08-01

## 用户可见变化

- 产品名称统一为 DeepSeek Workspace。
- 接入 AgentLib 已注册的全部模型提供者；生产项目与发布产物不包含 Mock/Fake 实现。
- 支持真实多轮流式对话，分别展示 reasoning 与 text。
- 支持以本地数据目录为工作区的 AgentLib 默认工具。
- 增加停止生成、可恢复错误重试和模型连接测试。
- 增加会话搜索、重命名、删除确认、最近删除撤销和按更新时间排序。
- 历史消息支持内联编辑；保存后截断该消息之后的上下文。
- 支持 Markdown、代码内容和当前会话 Markdown 导出。
- 增加智能自动滚动、空状态、加载状态和错误状态。
- 增加本地诊断摘要、日志目录、日志清理和隐私保护。
- 会话格式升级到 SchemaVersion 2，并兼容自动迁移 v1。

## 安装与运行

### 系统要求

- Windows 10 或 Windows 11 x64
- .NET 10 Desktop Runtime
- 有效的模型服务端点、模型和 Key

### 发布形式

本版本提供 `win-x64` framework-dependent zip：

1. 安装 .NET 10 Desktop Runtime。
2. 解压 zip 到普通可写目录。
3. 配置 `AgentConfiguration.json`。
4. 运行 `DeepSeekWpf.exe`。

发布包不是单文件、自包含或裁剪包。

## 首次配置

默认 Agent 配置文件：

`%LocalAppData%\DeepSeekWpf\AgentConfiguration.json`

如需使用其他位置，设置环境变量：

`DEEPSEEKWPF_AGENT_CONFIG=<配置文件完整路径>`

环境变量路径优先于默认路径。配置文件负责保存端点、Key、模型定义和主模型；设置页只选择已注册模型，不读取、编辑或回显 Key。

首次打开后：

1. 在外部配置文件中填写合法 JSON。
2. 打开设置页并点击“重新加载配置”。
3. 选择模型。
4. 点击“测试连接”。
5. 保存设置并返回对话工作区。

合法配置示例见项目根目录 `README.md`。不要直接复制带 `//` 注释的 AgentLib 模板作为 JSON 文件。

## 设置迁移

- 设置文件仍位于 `%LocalAppData%\DeepSeekWpf\settings.json`。
- 旧 `ModelName` 会在加载时迁移为 `SelectedModelSpecifier`。
- 旧 API 地址和 API Key 不再从设置文件读取、使用或写回。
- 请将端点和 Key 手工迁移到外部 `AgentConfiguration.json`。若曾使用旧文件名 `agent-endpoints.json`，请重命名或通过 `DEEPSEEKWPF_AGENT_CONFIG` 指向旧文件。
- 缓存、数据、日志路径和发送快捷键设置继续保留；无法解析的设置文件会恢复并保存默认设置，同时记录本地日志。

升级前建议备份整个 `%LocalAppData%\DeepSeekWpf` 目录。

## 会话迁移

- 当前会话文件写入 `SchemaVersion = 2`。
- v1 或缺少版本的会话在加载时自动转换为 v2 内存模型，并在下次保存时写为 v2。
- 单个损坏或版本过新的文件不会阻止其他会话加载。
- 出错原文件保留在数据目录的 `Sessions` 子目录中，便于备份和修复。

## 已知限制

- 发布包依赖预装 .NET 10 Desktop Runtime。
- 配置文件中的 Key 是明文外部文件，用户必须自行保护文件 ACL、备份和分享范围。
- 切换数据目录不会自动搬迁旧会话，需要手工复制。
- 删除撤销只保留最近一次删除，关闭应用后不可撤销。
- 编辑消息采用“截断后续上下文”语义，不提供会话分支树。
- 自动重试不会在已经开始流式输出后执行，以避免重复内容。
- 真实账号端到端、性能、DPI、高对比度、键盘完整性和 Windows 版本矩阵仍待人工验收。

## 隐私

- Key 仅由外部 Agent 配置文件管理。
- 设置、会话、日志和诊断摘要不主动记录 Key、认证头或完整请求体。
- 日志默认不记录聊天正文。
- Agent 工作区工具可处理当前数据目录中的内容，请只放置允许模型访问的文件。
- 应用不自动上传日志、诊断、会话或配置。
- 获取支持时不要分享 Key、Agent 配置文件或聊天正文。

## 回滚与备份

升级或回滚前：

1. 退出应用并确认没有正在生成的回复。
2. 备份 `%LocalAppData%\DeepSeekWpf`，以及 `DEEPSEEKWPF_AGENT_CONFIG` 指向的自定义配置文件。
3. 保留原发布 zip。

回滚时：

1. 使用原版本发布文件覆盖或解压到独立目录。
2. 恢复对应版本的设置和会话备份。
3. 注意旧版本可能无法读取 SchemaVersion 2 会话；不要让旧版本直接覆盖唯一的 v2 数据副本。
