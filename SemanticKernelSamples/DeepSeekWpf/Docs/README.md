## 文档维护规则

- 当前需求、设计、使用和支持文档必须与代码保持一致。
- 历史记录可保留当时事实，但必须醒目标注历史状态。
- 经验文档只沉淀可复用方法，不写单次项目流水账。
- 自动化构建/测试/发布结果与人工性能、DPI、可访问性、真实账号验收必须分开记录。
- 未人工执行的项目只能标记为“待人工实测”，不得写成已通过。
