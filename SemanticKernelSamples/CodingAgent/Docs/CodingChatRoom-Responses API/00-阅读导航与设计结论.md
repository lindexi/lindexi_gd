# CodingChatRoom Responses API 设计文档

## 文档目标

本文档集定义 `CodingChatRoom.AvaloniaShell` 对 OpenAI Responses API 的产品级支持方案。Responses 是独立的一等执行路径，不适配成 Chat Completions，也不替换现有 `CodingAgent`。

本文档集包含早期实验与当前实现。当前架构以 02、文件路径以 09、能力状态以 10 为准；原生 Compact 调查、测试清理及未确认问题以 14 为准。12 是早期消息 API 实验记录，不代表当前 Shell 或协议持久化仍未实现。

基础多轮、工具、思考强度、停止、磁盘恢复、请求边界插话已接通并有定向真实记录；原生 Compact 调用及客户端边界通过，压缩后语义续聊未通过。禁止把目标、诊断完成或 HTTP 成功写成产品能力已验收。

## 权威约束

1. `AgentLib` 公开 API 原则上只允许兼容性增加，不允许删除、改名或改变参数语义。本轮明确允许的例外是为 `IManualSendMessageContext` 新增 `LanguageModel` 属性并同步实现方；不扩大到其他接口。
2. `AgentLib.Coding` 允许为本次架构调整进行破坏性变更，但现有 `CodingAgent` 执行能力和 CodingAgent 分支必须完整保留。
3. 用户只在新运行入口处通过 ToggleButton 选择执行引擎；运行开始后不支持也不防御来回切换。
4. Responses 路径直接使用 `OpenAI.Responses` 的 Items、流式事件和有状态语义，不经过 `IChatClient` 适配。
5. 两条路径共享提示词、工作区工具、展示模型和应用协调层，但不共享协议状态机。
6. 唯一界面变化是在“启用 dotnet run”右侧增加一个经过布局设计的 ToggleButton。
7. 禁止修改设置界面、设置文件格式及其读写逻辑；现有模型配置均可进入 Responses 分支，真实端点不支持时按服务返回错误处理。
8. SDK 托管工具中，本方案要求第一等支持的只有 Web Search。
9. 继续使用统一的 `AgentApiEndpointManager`，配置部分不变；保持 `ILanguageModel` 不变，由 `OpenAILanguageModel` 直接实现新增接口 `IResponsesClientProvider`，通过 `GetResponsesClientAsync()` 返回 SDK 原生 Responses 客户端。现有 JSON 配置链路创建的所有模型天然具备该接口，由 AgentLib 实现和测试保证，不交给 Shell 包装或补建客户端。禁止将一个模块的实现缺陷交给另一个尚未实现的模块兜底。接口获取集中在 Responses 执行入口，不自动回退。
10. 面向长期维护，禁止补丁式实现、过度设计和过度防御。本地客户端提供接口的判断不代表服务端支持性判断；不增加远端支持性预检查、能力标记、网络探测或以可空客户端表示不支持，按实际请求结果处理服务端错误。详见 [03-AgentLib兼容扩展设计](03-AgentLib兼容扩展设计.md)。

11. 保留 `CreateManualSendMessageContextAsync` 的异步创建逻辑、`ChatClient` 属性及两个 Agent 辅助方法，仅为上下文新增 `LanguageModel`，保存创建 Chat 客户端时使用的同一模型对象。创建令牌不存入上下文，后续执行显式传入自己的取消令牌。Responses 执行不进入 `CopilotChatManager`；消息通过延迟创建的 `ResponseInfo` 接收原生响应，片段追加与通知共用现有消息体系，详见 12。

## 总体结构

```text
ChatViewModel
  └─ 在运行入口读取一次 IsResponsesApiEnabled
       ├─ false → CodingWorkTaskController → CodingAgentChatRunner → CodingAgent
       └─ true  → CodingWorkTaskController → ResponsesCodingChatRunner → ResponsesCodingAgent

AgentLib.Coding
  ├─ CodingAgent
  ├─ ResponsesCodingAgent
  └─ ResponsesCodingAgentRunner
```

Responses 直接复用 CodingAgent 既有工作区工具入口。CodingWorkspaceRuntime/RunLease 设计已否决并删除，不恢复。原生状态由 CopilotChatSession 的 CopilotResponsesSession 持有；只在存储初始化恢复，不从展示消息或 Chat 历史重建。运行结果统一为 ICodingAgentRunResult。

手动/自动压缩完全使用服务端 /responses/compact，任何失败禁止回退。无历史由 TryCompactConversationAsync 返回 false，错误和取消传播。
