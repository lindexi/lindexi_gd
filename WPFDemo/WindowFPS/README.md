# WindowFPS（窗口帧率计）

Windows 11 桌面工具。通过系统捕获选择器选择目标，在小窗口中显示捕获 FPS。

## 启动

- 开发：使用 .NET 8 SDK 在 Windows 上打开并运行 `WindowFPS.csproj`。
- 分发：运行 Windows x64 自包含发布目录中的 `WindowFPS.exe`，无需另外安装 .NET。
- Windows 11 22H2 及以上版本使用系统 Mica；不能启用时使用纯色背景。

## 读数含义

每 250 毫秒更新一次，读数是最近 1 秒内收到的捕获帧数。它不是目标程序的渲染帧率，也不是显示器刷新率。统计过程不把图像像素复制到 CPU。

如果系统选择器也列出显示器，请选择要监测的应用窗口。单击「取消」不会中断当前监测。

## 手动验收

1. 启动后应显示「—」和「选择窗口」。
2. 选择一个能以 15 或 30 FPS 播放动画的窗口，观察读数是否能区分两个速度。实际读数可能与动画设置不同。
3. 暂停动画；如果系统不再送帧，约一秒后应显示「暂无新帧」和「—」。恢复动画后应自动更新。
4. 调整目标窗口大小，确认捕获继续。关闭目标后应显示「捕获已停止」。
5. 单击「更换窗口」并取消，应保留现有目标；换选另一个窗口后应更新窗口标题和读数。
